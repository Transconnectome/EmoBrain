# Legacy Qwen2.5 Pipeline

This directory preserves the pre-2026-07-22 implementation and configs only
for provenance of historical output JSON files. It is not a supported EmoBrain
pipeline.

The canonical implementation is `project/code/` and uses Qwen3-VL-4B with E1
ViT or E2 BFM. Do not use the ridge-latent encoder or Qwen2.5 configs here for
new experiments.
