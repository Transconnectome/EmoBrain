CCN_Emotion — 프로젝트 전체 흐름

감정 라벨 없이 학습된 비디오 모델의 emergent emotion 표상이 인간 뇌에서 사용되는지의 검증
CCN 2026 accepted poster · Moon · 마지막 정리 2026-05-27

①출발점: 우리는 어떻게 영상을 보고 감정을 느끼는가

호러 영상을 보면 무섭다. 멜로 영상을 보면 슬프다. 시각으로 들어온 정보가 뇌 안에서 어떻게 감정이 되는가, 이게 오래된 affective neuroscience 의 질문이다.

여기에 두 입장이 경쟁한다.

Reentry 관점 (고전)

시각 피질은 그냥 객체와 장면을 인식하는 중립 처리기다. 얼굴, 어둠, 빠른 모션 같은 일반 visual feature 만 뽑아낸다. 그 다음에 amygdala 나 prefrontal cortex 같은 별도 영역이 feedback 으로 "이건 무서움" 이라는 라벨을 덧입힌다. 시각 자체는 감정과 무관하다.

Intrinsic 관점 (Kragel 2019)

시각 피질이 이미 emotion schema 를 인코딩한다. 감정 카테고리 라벨로 학습한 CNN 의 internal 표상이 visual cortex fMRI 와 정렬되고, 15+ emotion category 가 시각 피질만으로 디코딩 가능. 시각 처리가 본질적으로 affect-relevant.

Kragel 의 발견은 강력하지만 결정적 약점이 있다. CNN 이 emotion 라벨로 supervised 학습됐다. 시각 피질에 emotion schema 가 있는 것처럼 보이는 게 자연 visual 통계 자체에 그 구조가 있어서인지, supervised 학습이 모델에 강제로 부과한 게 우연히 시각 피질과 닮은 건지 분리가 안 된다. Circularity 문제.

②변화: 최근 두 발견이 intrinsic 쪽으로 무게를 더했다

Bao et al. (2024) PLoS Computational Biology

Object recognition 만 학습한 CNN — 즉 감정 라벨 한 번 안 본 모델 — 의 internal 뉴런 일부가 자발적으로 emotion-selective 반응 을 발달시킨다. 자연 통계 + 객체 인식 목표만으로 만들어진 시각 hierarchy 가 부산물로 emotion-relevant computation 을 포함한다.

Conwell et al. (2025) PNAS

감정 supervision 없이 학습된 180 개 visual model 을 인간 arousal-valence 평가에 테스트. emotion 라벨 없이 학습된 모델들이 인간 affective behavior 분산의 majority 를 설명 — emotion-supervised 모델만큼 잘. "Perceptual primacy of feeling."

이 둘이 합쳐서 affectless machines 가설 을 만든다.

시각 학습 시스템은 어떤 감정 supervision 없이도 emotion-relevant 표상을 emergent 로 발달시킨다.

③빈자리: brain 이 안 봤다

Bao 는 model 내부를 봤다. Conwell 은 인간 행동을 봤다. 둘 다 brain 을 직접 안 봤다.

결정적 질문이 남는다.

Affectless model 의 emergent emotion 표상이 인간 뇌의 시각 처리에 실제로 사용되는가?

만약 사용된다면, affectless machines 가설은 model 과 행동을 넘어 신경 표상까지 확장. Kragel 의 supervision circularity 가 없는 형태로 intrinsic emotion in visual cortex 를 강화.

만약 사용되지 않는다면, 가설이 model 과 행동에 한정. Brain 의 emotion 처리는 시각 표상의 어디 다른 곳에서 — 또는 시각 너머에서 — 일어난다. Reentry 관점에 가까운 결과.

이 빈자리를 채우는 것이 CCN_Emotion 의 목표 다.

④접근: 한 모델 안에서 두 subspace 가 만나는지를 본다

V-JEPA2 (Meta, 2025) 를 쓴다. 비디오 1 백만 시간 이상으로 학습. 감정 라벨 한 번도 보지 않음 — affectless machines 가설의 가장 깨끗한 instance.

Brain-JEPA (NeurIPS 2024) 로 인코딩한 fMRI 와, 별도로 raw BOLD 를 secondary track 으로 사용. Horikawa et al. (2020) 의 5 명 × 2,196 감정 영상 데이터셋.

V-JEPA2 의 1408 차원 비디오 표상을 100 PCs 로 줄이고, 세 가지 측정.

측정 1 (M1) — Brain-aligned subspace 식별

각 V-JEPA2 PC 가 Brain-JEPA 로부터 ridge regression 으로 선형 예측 가능한지 본다. 100 PCs 중 통계 보정 후 살아남는 PCs.

DONE 3 개 PC survive (PC1 R²=0.373, PC2=0.075, PC3=0.088). 단 R² clipping artifact 검증 진행 중.

측정 2 (M2) — Emotion-encoding subspace 식별

각 V-JEPA2 PC 가 emotion rating 을 얼마나 잘 예측하는지 본다. 두 종류 metric: 연속 회귀 (R², Pearson r) 로 34 카테고리 점수 + arousal-valence 를, 카테고리 디코딩 (top-k accuracy, ROC-AUC) 으로 영상별 top-rated category 를.

NEXT Exp 30 작성 완료, 사용자 sbatch 대기.

측정 3 (M3) — 두 subspace 의 overlap

M1 의 brain-aligned PCs 와 M2 의 top emotion-encoding PCs 가 같은 PCs 인가? Jaccard coefficient, Spearman rank correlation, permutation null 로 정량화.

⑤의미: 세 가지 outcome 이 각각 다른 답을 준다

Outcome A — overlap 큼

Brain 이 V-JEPA2 의 emotion-encoding 부분을 정확히 사용. Brain 의 시각 처리가 emotion category 라는 dimension 으로 영상을 organize. 객체나 장면이 아니라.

함의: Affectless machines 가설이 brain 까지 확장. Kragel 의 발견을 supervision circularity 없이 강화.

Outcome B — overlap 없음

Brain 이 V-JEPA2 의 emotion-encoding 과 다른 부분을 사용. Brain 의 시각 처리는 일반 visual recognition (객체, 장면, 모션) 으로 organize, emotion 은 시각 너머에서.

함의: Affectless machines 가설이 model 과 행동에 한정. Reentry 관점 지지.

Outcome C — 부분 overlap

Brain 이 emotion-encoding 과 non-emotion-encoding 을 혼합해서 사용. Quantitative characterization 필요.

함의: Pillar 3 (architecture baseline) 로 SSL 비디오 특이성 결정.

세 outcome 모두 publishable. 어느 쪽이 진짜인지 모른 채 출발해야 calibrated science.

⑥통제: 세 pillar 로 결과의 해석을 좁힌다

기본 측정만으로는 부족. 결과가 trivial 한 자극 visual coherence 의 반영인지, 진짜 emergent affective 발견인지 구분 안 됨.

Pillar 2 — 일반 visual baseline 통제
V-JEPA2 PCs 에서 DINOv2 (object), Places365 (scene), optical flow (motion), Sadeghi 139 (저수준 통계) 를 partial out. Overlap 이 표준 visual recognition 으로 환원 가능한가?
Pillar 3 — Architecture baseline
Untrained V-JEPA2, ImageNet-supervised ViT-L, VideoMAE 에 동일 pipeline. Overlap 이 자기지도 비디오 학습 특이인가, 어떤 vision model 도 같은가?
Pillar 4 — Brain representation track
Brain-JEPA 대신 raw BOLD (450 parcels). Overlap 이 BFM-encoded brain artifact 인가, raw fMRI 에서도 일관되는가?

셋 다 통과해야 강한 주장 가능. 일부만 통과하면 modest 발견. 다 실패해도 null result 로서 의미 있다.

⑦더 큰 맥락: representational alignment paradigm

Muttenthaler et al. (2025) Nature

Vision foundation model 의 표상이 인간의 multi-level conceptual hierarchy 를 잡지 못한다. Human-similarity-distilled supervision (AligNet) 으로 fine-tune 하면 misalignment 가 수리되고 ML downstream 도 좋아진다.

Muttenthaler 의 핵심 발견 — 자연 model 표상이 인간 / 뇌 관련 구조와 sparse 하게만 align 된다 — 이 우리 M1 결과 (100 PCs 중 3 개만 brain-aligned) 의 광역 맥락이다.

⑨Accepted abstract 의 leap 문제

CCN 2026 에 accept 된 abstract 는 brain-aligned subspace 를 "affective subspace" 로 명명했고 "emotion schemas embedded within visual statistics" 로 해석했다. 두 단계 점프다.

Leap 1 (명명)
V-JEPA2 PCs 는 정의상 visual feature axis. "Affective" 라 부르려면 그 PCs 가 일반 visual category 통계가 아닌 emotion-relevant 정보를 담는다는 것을 보여야 한다. 그게 M2 가 채우는 자리.
Leap 2 (메커니즘 인용)
Kragel 2019 는 supervised, Conwell 2025 는 행동만. 둘 다 우리 setup (자기지도 + brain) 의 메커니즘 증거가 못 된다. 그게 M3 overlap 분석이 채우는 자리.

현재 framework 는 이 두 leap 을 interpretive 가정에서 testable 가설로 변환했다. M1+M2+M3 모두 측정되기 전까지 brain-aligned subspace 는 emotion attribution 없이 "brain-aligned visual subspace of V-JEPA2" 로 가장 정직하게 기술된다.

Camera-ready (6/11) 에서 abstract 의 over-claim 언어를 calibrated 수준으로 약화. 8 월 포스터까지 M2, M3, Pillar 2 결과 확보. 풀 페이퍼로 갈지 여부는 결과 본 후 결정.

⑪한 줄 요약

감정 라벨 없이 자연 비디오만 학습한 V-JEPA2 모델 안에서, brain 이 align 하는 visual 부분과 emotion 을 인코딩하는 visual 부분이 같은 PCs 인지 측정한다. 같으면 affectless machines 가설이 brain 까지 확장된다는 첫 직접 증거. 다르면 시각 처리는 affect-neutral 이고 emotion 은 시각 너머에서 만들어진다는 reentry 관점 지지. 어느 결과든 affective neuroscience 의 살아있는 debate 에 직접 영향.
