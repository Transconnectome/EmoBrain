0. One-Sentence Summary
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FEELIN는 emotion-labeled fMRI에서 Brain Foundation Model이 emotion-relevant representation을 얼마나 잘 잡는지 확인하기 위해, 먼저 Dataset x BFM x Task master matrix를 구축하고 채우는 모델 개발 프로젝트입니다.
정식 이름
Brain Foundation Model for Emotion-aware Experience Learning In Naturalistic Data
핵심 질문
어떤 Brain Foundation Model이 어떤 emotion fMRI dataset과 task에서 emotion-relevant representation을 가장 안정적으로 잡는가?
현재 목표
완성형 "Emotion Foundation Model"을 바로 주장하는 것이 아닙니다.
현재 목표는 Dataset x BFM x Task master matrix를 채워 model-development decision을 내릴 수 있는 benchmark 기반을 구축하는 것입니다.

1. Background & Significance
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1.1 Brain Foundation Models의 등장
최근 fMRI와 neural signal 분야에서도 foundation model 흐름이 빠르게 생기고 있습니다.
SwiFT, BrainLM, Brain-JEPA, NeuroSTORM, Omni-fMRI, Brain-OF, Brain-DiT 계열은 대규모 brain activity에서 transferable representation을 학습하려는 모델들입니다.
하지만 대부분의 BFM은 emotion을 중심으로 설계된 모델이 아닙니다.
Emotion task가 downstream benchmark 중 하나로 들어갈 수는 있지만, emotion-specific representation을 잘 만들기 위한 objective나 architecture가 명시적으로 설계된 경우는 드뭅니다.
FEELIN에서의 모델 역할
SwiFT
- 4D fMRI spatiotemporal backbone
- FEELIN의 기본 brain encoder
BrainLM / Brain-JEPA / NeuroSTORM / Omni-fMRI
- 기존 BFM transfer baseline
- generic brain representation이 emotion으로 전이되는지 확인하는 비교점
TRIBE v2
- fMRI encoder가 아니라 stimulus-to-brain encoding model
- video/audio/language stimulus에서 predicted brain response를 생성
- FEELIN에서는 첫 BFM benchmark 이후 stimulus-only control, teacher, alignment target으로 사용
현재 Dataset x BFM x Task benchmark의 BFM axis
- SwiFT
- BrainLM
- Brain-JEPA
- NeuroSTORM
SwiFUN은 direct emotion-fMRI BFM candidate가 아니므로 첫 benchmark matrix에는 넣지 않습니다.
1.2 왜 Emotion은 단순 Label Prediction 문제가 아닌가
많은 machine learning task에서는 emotion을 다음처럼 다룹니다.
image/video/audio/text/fMRI -> anger / fear / joy / sadness / neutral
이 접근은 필요하지만 충분하지 않습니다.
Emotion은 다음 요소들이 동시에 얽혀 있습니다.
- Dimensional: arousal, valence, dominance, intensity
- Categorical: fear, joy, sadness, anger, disgust, awe 등
- Multi-label: 여러 감정이 동시에 존재 가능
- Dynamic: 영화나 이야기 속에서 시간에 따라 변화
- Componential: appraisal, motivation, expression, physiology, feeling
- Context-dependent: 같은 얼굴/장면도 서사 맥락에 따라 달라짐
- Stimulus-dependent: visual, auditory, language, social cue가 함께 작동
- Subject-dependent: 같은 stimulus라도 개인마다 반응이 다름
따라서 FEELIN의 질문은 단순히 "fMRI로 emotion label을 맞힐 수 있는가?"가 아닙니다.
더 정확한 질문은 다음입니다.
fMRI brain dynamics에서 emotion-relevant representation을 더 잘 학습하려면 어떤 모델 구조와 학습 전략이 필요한가?
1.3 Affective Computing의 Task 변화
Affective computing에서도 emotion task는 단순 classification에서 점점 확장되고 있습니다.
최근 LLM/VLM/MLLM 기반 affective computing은 emotion recognition뿐 아니라 emotion reasoning, cue grounding, cause/trigger inference, affective captioning, multimodal emotion understanding까지 다룹니다.
Task ladder
1. Sentiment / valence classification
   - Output: positive / neutral / negative
   - FEELIN 의미: IAPS, Affective Videos식 낮은 난이도 check
2. Discrete emotion classification
   - Output: anger, fear, joy 등 single label
   - FEELIN 의미: 기본 baseline task
3. Multi-label emotion prediction
   - Output: 여러 emotion label 또는 probability vector
   - FEELIN 의미: Horikawa-style high-dimensional target과 가까움
4. Dimensional affect regression
   - Output: arousal, valence, dominance, intensity
   - FEELIN 의미: fMRI에서 가장 먼저 확인할 sanity ladder
5. Continuous affect tracking
   - Output: window/frame-level affect trajectory
   - FEELIN 의미: Emo-FilM, REELMO, movie-window 설계와 연결
6. Emotion cause / trigger reasoning
   - Output: cue, cause, intent, appraisal, rationale
   - FEELIN 의미: stimulus-side auxiliary target
7. Affective captioning / QA
   - Output: natural-language emotion description
   - FEELIN 의미: fMRI latent와 embedding alignment target
FEELIN는 이 task ladder를 fMRI-compatible하게 번역해야 합니다.
첫 단계에서는 측정 가능한 regression, classification, multi-label task를 사용합니다.
이후에는 MLLM-derived caption, rationale, cue embedding을 stimulus-side auxiliary target으로 사용합니다.
단, fMRI가 직접 natural-language reasoning을 한다고 주장하지 않습니다.
1.4 왜 SwiFT-first인가
FEELIN의 기본 brain backbone은 SwiFT입니다.
이유 1
SwiFT는 local lab backbone이므로 가장 적극적으로 수정할 수 있습니다.
Frozen feature extraction에서 끝나는 것이 아니라, emotion-specific head, subject adapter, affective token, continued pretraining, stimulus-brain alignment module까지 실제로 개발할 수 있습니다.
이유 2
SwiFT는 4D fMRI를 직접 다루는 spatiotemporal transformer 계열입니다.
Emotion은 naturalistic stimulus, time-varying context, subject-specific response와 연결되어 있으므로, 4D fMRI encoder를 emotion-specific하게 발전시키는 질문이 FEELIN의 중심이 됩니다.
SwiFT-first의 의미
SwiFT를 단순 baseline으로만 쓰지 않고, emotion-specific naturalistic fMRI encoder로 발전시키는 방향을 먼저 탐색한다.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2.1 핵심 테제
FEELIN의 핵심 테제는 다음입니다.
Emotion fMRI modeling은 단순 emotion label prediction이 아니라, brain dynamics, naturalistic stimulus dynamics, affective annotation이 만나는 representation learning 문제입니다.
작은 emotion fMRI dataset에 classifier를 붙이면 점수는 얻을 수 있습니다.
그러나 그 점수가 정말 emotion-specific brain representation을 의미하는지는 불분명합니다.
높은 성능은 다음 shortcut에서 나올 수 있습니다.
- stimulus identity
- subject identity
- low-level visual motion
- luminance / scene cut
- audio energy / speech onset
- generic arousal / attention
- HRF timing artifact
- preprocessing artifact
- label imbalance
따라서 FEELIN는 단일 score가 아니라 다음 증거를 함께 봐야 합니다.
1. simple ROI/ridge baseline 대비 개선
2. frozen SwiFT 대비 adapter/fine-tuning 개선
3. stimulus-only baseline 대비 brain-specific signal
4. arousal뿐 아니라 valence, multi-label, high-dimensional target 성능
5. representation geometry와 emotion rating geometry의 정렬
6. subject/stimulus split에서의 일반화
7. cross-dataset transfer
8. low-level visual/audio shortcut control
2.2 Four-Axis FEELIN Framework
Axis 1. Brain backbone
SwiFT / BrainLM / Brain-JEPA / NeuroSTORM / other BFMs
Axis 2. Naturalistic fMRI pretraining
resting/generic BFM -> movie/story stimulus-locked fMRI representation
Axis 3. Stimulus-brain alignment
video/audio/text stimulus -> brain response -> shared emotion latent
Axis 4. Affective AI target richness
label -> intensity -> distribution -> trajectory -> cue/rationale/caption embedding
이 네 축의 조합이 FEELIN의 모델 개발 공간입니다.
2.3 왜 Naturalistic Movie/Story fMRI인가
Naturalistic movie/story fMRI를 쓰는 이유는 단순히 "movie가 resting-state보다 더 현실적이다"가 아닙니다.
그 말은 너무 약합니다.
정확한 가설은 다음입니다.
작은 emotion-labeled fMRI dataset으로 바로 fine-tuning하기 전에, SwiFT가 visual, auditory, language, social, narrative cue에 의해 유도되는 stimulus-locked brain dynamics를 먼저 학습해야 하는가?
Resting-state fMRI는 intrinsic connectivity, subject trait, baseline network structure를 학습하는 데 유리합니다.
하지만 emotion during naturalistic experience는 외부 stimulus가 시간 속에서 펼쳐질 때 만들어집니다.
Movie/story fMRI는 다음 정보를 제공합니다.
- face / body motion
- scene transition
- visual saliency
- voice / speech onset
- music / auditory intensity
- semantic context
- social interaction
- narrative buildup
- expectation / surprise
- emotional arc
따라서 naturalistic pretraining은 emotion label이 많아서 쓰는 것이 아니라, emotion target을 만드는 stimulus-evoked brain dynamics를 미리 학습하기 위해 사용합니다.
2.4 HCP는 첫 후보이지 전체 전략이 아니다
HCP Young Adult 7T movie는 scale, 표준화, 7T quality, resting/movie가 함께 있는 구조 때문에 첫 continued-pretraining 후보가 될 수 있습니다.
하지만 HCP 하나로 모든 naturalistic pretraining 논리를 정당화할 수는 없습니다.
Dataset 선택은 model hypothesis별로 해야 합니다.
HCP 7T movie
- 왜 쓰는가: large-subject movie fMRI
- 확인할 질문: stimulus-locked pretraining이 Horikawa/Emo-FilM transfer를 개선하는가?
CNeuroMod / Algonauts 2025
- 왜 쓰는가: video/audio/transcript + fMRI encoding resource
- 확인할 질문: TRIBE-style alignment가 emotion target에 도움이 되는가?
StudyForrest
- 왜 쓰는가: long coherent film
- 확인할 질문: long-film continuity가 temporal representation에 도움이 되는가?
Narratives
- 왜 쓰는가: spoken story + transcript
- 확인할 질문: visual cue 없이 language/narrative context를 align할 수 있는가?
101 Dalmatians
- 왜 쓰는가: audiovisual/auditory/visual conditions
- 확인할 질문: modality별 contribution을 분리할 수 있는가?
Emo-FilM
- 왜 쓰는가: fMRI + emotion/component annotation
- 확인할 질문: naturalistic pretraining의 downstream validation
REELMO
- 왜 쓰는가: movie affect trajectories + fMRI participants watched Jojo Rabbit
- 확인할 질문: REELMO dynamic fMRI benchmark가 가능한가? annotation은 이후 stimulus-side affect trajectory / rationale target으로 쓸 수 있는가?
2.5 Naturalistic Pretraining의 위험
Movie/story pretraining은 강력하지만 위험합니다.
모델이 emotion representation을 배운 것이 아니라 다음 shortcut을 배울 수 있습니다.
- low-level visual motion
- luminance
- scene cut
- face/object category
- auditory energy
- speech onset
- music intensity
- stimulus identity
- subject synchronization
- generic arousal
그래서 모든 naturalistic pretraining은 반드시 control을 포함해야 합니다.
필수 control
1. resting/generic SwiFT vs naturalistic-pretrained SwiFT
   - naturalistic fMRI가 transfer value를 주는지 확인
2. low-level visual/audio feature control
   - motion/luminance/audio shortcut인지 확인
3. vision-only/audio-only/text-only ablation
   - 어떤 modality가 transfer를 담당하는지 확인
4. stimulus-only baseline
   - label이 stimulus만으로 설명되는지 확인
5. arousal-only vs high-dimensional target
   - 단순 arousal 개선인지 rich emotion representation인지 확인
6. Horikawa vs Emo-FilM transfer
   - short video geometry와 film component target 모두에 통하는지 확인
2.6 왜 TRIBE v2인가
TRIBE v2는 SwiFT의 대체제가 아닙니다.
Native direction
SwiFT
observed fMRI -> brain latent -> emotion
TRIBE v2
video/audio/language stimulus -> predicted brain response
즉 TRIBE v2는 fMRI encoder가 아니라 stimulus-to-brain encoding model입니다.
그러나 바로 그 점 때문에 FEELIN에 중요합니다.
TRIBE v2가 던지는 질문
emotion target은 observed fMRI에서만 예측되는가, 아니면 video/audio/text stimulus context만으로도 상당 부분 설명되는가?
TRIBE v2 활용 방식
1. stimulus-only baseline
   - video/audio/text -> emotion target
   - label이 stimulus만으로 설명되는지 확인
2. frozen teacher
   - video/audio/text -> predicted brain response
   - stimulus-to-brain prior로 사용
3. teacher distillation
   - TRIBE-predicted brain latent/map -> SwiFT latent target
   - stimulus-brain structure를 SwiFT에 전달
4. dual encoder
   - stimulus latent + fMRI latent -> shared latent
   - brain-stimulus-emotion representation 학습
5. auxiliary encoding loss
   - stimulus feature -> fMRI response
   - emotion training regularization
2.7 왜 Affective LLM/VLM인가
Affective computing의 최근 흐름은 label prediction을 넘어 cue grounding, emotion captioning, cause/trigger reasoning, multimodal emotional intelligence benchmark로 이동하고 있습니다.
FEELIN가 이 흐름에서 배울 점
- emotion target을 단순 category로만 두지 않는다.
- stimulus-side affect representation을 더 풍부하게 만든다.
- caption/rationale/cue embedding을 fMRI latent와 align할 수 있다.
- brain response를 affective AI representation의 biological alignment signal로 사용할 수 있다.
가능한 주장
fMRI response can regularize or evaluate affective stimulus representations.
아직 피해야 할 주장
fMRI directly performs natural-language emotional reasoning.

3. Gap in the Literature
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Gap 1. Existing fMRI BFMs are generic, not emotion-organized
SwiFT, BrainLM, Brain-JEPA, NeuroSTORM 등은 brain-side foundation model space를 만듭니다.
그러나 대부분의 pretraining objective는 emotion-specific하지 않습니다.
Emotion은 downstream task로 포함될 수 있지만, emotion representation을 중심으로 architecture와 objective를 설계한 경우는 드뭅니다.
FEELIN gap
SwiFT-style fMRI encoder를 emotion-specific하게 발전시키는 model-development framework가 부족하다.
Gap 2. Affective computing foundation models lack brain grounding
Affective computing에서는 LLM/VLM/MLLM 기반 emotion recognition, reasoning, captioning, benchmark가 빠르게 늘고 있습니다.
그러나 이 모델들은 보통 external label, human judgment, stimulus-only benchmark로 평가됩니다.
Emotional stimulus에 대한 fMRI response와 직접 연결되는 경우는 드뭅니다.
FEELIN gap
Can brain responses provide biological grounding for affective AI representations?
Gap 3. Stimulus-to-brain models optimize encoding, not emotion representation
TRIBE, TRIBE v2, VIBE, Algonauts-style models는 naturalistic stimulus로 fMRI response를 예측합니다.
하지만 native objective는 fMRI encoding이지 emotion representation learning이 아닙니다.
FEELIN gap
Can stimulus-to-brain encoding models be modified into emotion-representation components?
Gap 4. Emotion fMRI datasets are small and heterogeneous
Emotion fMRI dataset은 매우 가치 있지만 규모와 형식이 제각각입니다.
Horikawa / Cowen
- 강점: high-dimensional emotion geometry
- 한계: short video, small fMRI N
Emo-FilM
- 강점: film context + component/appraisal annotation
- 한계: limited fMRI N, timing/annotation complexity
Affective Videos
- 강점: arousal/valence quick check
- 한계: small N, short clips
IAPS fMRI
- 강점: positive/neutral/negative beta maps
- 한계: raw 4D time series가 아님
NeuroEmo
- 강점: cross-cultural emotion clips
- 한계: label mapping and stimulus access 확인 필요
Koide-Majima / Nishimoto
- 강점: emotional movie fMRI candidate
- 한계: access-dependent
FEELIN gap
작은 dataset 하나에 end-to-end model을 바로 학습하기보다, dataset/model/task를 공정하게 비교하는 benchmark surface가 먼저 필요하다.
Gap 5. Emotion task design is often too narrow
Emotion을 single-label classification으로만 보면 다음 구조를 놓칩니다.
- intensity
- mixed emotion
- high-dimensional affect geometry
- component/appraisal structure
- continuous trajectory
- stimulus cue / cause / rationale
FEELIN gap
Emotion fMRI modeling에는 single target이 아니라 task ladder가 필요하다.

4. Research Question
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Main Question
작은 emotion fMRI dataset 조건에서, 어떤 model architecture와 training objective가 가장 transferable한 emotion-relevant brain representation을 만드는가?
Sub-Questions
1. BFM transfer
   - 기존 SwiFT/BFM representation이 emotion target으로 전이되는가?
   - Simple ROI/ridge baseline보다 좋은가?
2. SwiFT emotion specificity
   - Frozen SwiFT가 충분하지 않다면 어떤 수정이 필요한가?
   - Multi-task head, adapter, subject adapter, affective token, temporal pooling 중 무엇이 유망한가?
3. Naturalistic pretraining
   - HCP/CNeuroMod/StudyForrest/Narratives-style movie/story fMRI pretraining이 Horikawa/Emo-FilM transfer를 개선하는가?
   - 개선이 단순 arousal이나 low-level visual/audio shortcut을 넘는가?
4. Stimulus-only explanation
   - Video/audio/text feature만으로 emotion target이 얼마나 설명되는가?
   - Brain model 성능을 brain-specific signal로 해석할 수 있는가?
5. Stimulus-brain alignment
   - SwiFT latent와 TRIBE/stimulus latent를 align하면 high-dimensional emotion target이 개선되는가?
   - Encoding loss가 emotion representation에도 도움이 되는가?
6. Brain-tuned affective AI
   - Affective LLM/VLM embedding을 fMRI response로 regularize할 수 있는가?
   - Caption/rationale/cue embedding이 brain-stimulus-emotion latent를 풍부하게 하는가?
Working Hypotheses
H1. Frozen SwiFT는 일부 emotion signal을 담고 있다.
- 기대 결과: arousal/category에서 ROI baseline 이상
- 주의: ROI/ridge가 계속 더 좋으면 preprocessing과 timing 확인
H2. Rich target에는 emotion-specific adaptation이 필요하다.
- 기대 결과: adapter/head가 valence/high-dimensional/component target 개선
- 주의: frozen feature만으로 충분하면 architecture 복잡화 보류
H3. Naturalistic pretraining은 transfer될 때만 의미 있다.
- 기대 결과: Horikawa/Emo-FilM high-dimensional/component target 개선
- 주의: visual/audio/arousal만 개선되면 emotion-specific claim 금지
H4. Stimulus-only baseline은 일부 target에서 강할 것이다.
- 기대 결과: V-JEPA/CLIP/audio/text feature가 label을 잘 예측
- 주의: brain-specific 해석을 보수적으로 해야 함
H5. Alignment는 high-dimensional target에서 유용할 수 있다.
- 기대 결과: RSA/CKA/retrieval/multi-label prediction 개선
- 주의: encoding만 좋아지고 emotion은 안 좋아질 수 있음
H6. Affective LLM/VLM은 target richness를 제공한다.
- 기대 결과: caption/rationale embedding alignment 개선
- 주의: fMRI가 직접 reasoning한다고 주장하지 않음

5. Methods

Experimental Design Overview
FEELIN는 처음부터 큰 end-to-end model을 주장하지 않습니다.
먼저 모든 Dataset x BFM x Task 조합을 펼친 master matrix를 만들고, 각 cell에 status, metric, failure reason, decision을 채운 뒤 model-development track을 선택합니다.
Phase 0. Setup and feasibility
Phase 1. Dataset x BFM x Task master matrix
Phase 2. Frozen BFM benchmark and statistical floors
Phase 3. BFM adaptation or pivot
Phase 4. Naturalistic/movie fMRI pretraining if benchmark supports it
Phase 5. Stimulus-only/TRIBE/alignment controls if needed
Phase 6. Consolidation and paper direction
──────────────────────────────
Phase 0. Setup and Feasibility
──────────────────────────────
Goal
실제로 어떤 dataset과 target을 지금 실행할 수 있는지 확인합니다.
해야 할 일
1. dataset local path 확인
2. fMRI shape / TR / timing 확인
3. event file과 HRF lag 가정 확인
4. emotion target matrix 생성
5. train/validation/test split 정의
6. blocked resource list 작성
7. compute requirement 추정
우선 확인할 dataset
- Horikawa / Cowen emotional video fMRI
- Emo-FilM
- Affective Videos
- IAPS fMRI NeuroVault
- NeuroEmo
- Koide-Majima/Nishimoto
- REELMO if accessible
HCP 7T movie, CNeuroMod/Algonauts, StudyForrest, Narratives, 101 Dalmatians는 현재 benchmark dataset axis가 아니라 이후 pretraining/alignment resource입니다.
- StudyForrest / Narratives는 access와 역할 정리부터
산출물
- setup/results/dataset_availability.md
- setup/results/target_construction.md
- split metadata
- blocked resource list
- first experiment cards
Decision rule
- Horikawa target이 바로 구성되면 NFx-001/NFx-002로 이동
- Emo-FilM timing이 복잡하면 Horikawa/Affective Videos/IAPS를 먼저 진행
- HCP는 downstream target이 아니라 pretraining-readiness source로 둠

Phase 1. Initial Benchmark
──────────────────────────────
Goal
fMRI와 emotion target 사이에 최소한의 예측 신호가 있는지 확인합니다.
Baseline order
1. ROI/parcel ridge baseline
2. dynamic FC baseline
3. frozen SwiFT feature + linear/ridge/MLP head
4. stimulus-only baseline
첫 실험 후보
NFx-001
- Dataset: Horikawa
- Model: frozen SwiFT + head
- Target: high-dimensional emotion vector
- Purpose: BFM transfer 확인
NFx-002
- Dataset: Horikawa
- Model: ROI/parcel ridge
- Target: high-dimensional emotion vector
- Purpose: simple baseline
NFx-003
- Dataset: Affective Videos
- Model: ridge / frozen SwiFT
- Target: arousal, valence
- Purpose: sanity check
NFx-004
- Dataset: IAPS fMRI
- Model: beta-map adapter
- Target: positive/neutral/negative
- Purpose: static affect check
NFx-005
- Dataset: Emo-FilM
- Model: ridge / frozen SwiFT
- Target: component/appraisal
- Purpose: naturalistic target readiness
Decision rule
- frozen SwiFT가 simple baseline보다 좋으면 adapter/head 확장
- simple baseline이 더 좋으면 preprocessing, HRF timing, feature extraction 점검
- stimulus-only가 너무 강하면 brain-specific claim을 조심하고 alignment/residual analysis 우선
──────────────────────────────
Phase 2. SwiFT Emotion Adaptation
──────────────────────────────
Goal
SwiFT를 small emotion fMRI dataset에 맞게 emotion-specific하게 수정합니다.
후보 수정
1. linear/ridge head
   - frozen feature readout
   - 첫 baseline
2. MLP emotion head
   - shallow nonlinear readout
   - frozen feature에 신호가 있을 때
3. multi-task head
   - arousal/valence/category/vector/component separate heads
   - heterogeneous target에 필요
4. subject adapter
   - subject embedding or adapter
   - subject variation이 클 때
5. dataset/domain adapter
   - dataset-specific small module
   - cross-dataset training에 필요
6. affective token/query pooling
   - affect readout token
   - 4D feature pooling 개선
7. late-block fine-tuning
   - late SwiFT block만 update
   - adapter가 underfit일 때
Primary targets
- Horikawa high-dimensional vector
- Emo-FilM component/appraisal target
- Affective Videos arousal/valence
- IAPS category
Decision rule
- adapter/head가 high-dimensional/component target을 개선하면 SwiFT adaptation track 유지
- arousal만 개선되면 physiology/dynamic objective 고려
- overfitting하면 trainable parameter를 줄이고 split validation 강화
──────────────────────────────
Phase 3. Naturalistic Movie/Story fMRI Pretraining
──────────────────────────────
Goal
stimulus-locked fMRI pretraining이 emotion transfer를 개선하는지 검증합니다.
Pretraining sources
HCP 7T movie
- first large-subject continued pretraining
CNeuroMod / Algonauts
- multimodal encoding/alignment
StudyForrest
- long-film continuity
Narratives
- language/story context
101 Dalmatians
- modality control
Candidate objectives
- masked fMRI segment modeling
- temporal contrastive learning
- JEPA-style future latent prediction
- subject-invariant contrastive learning
- stimulus-conditioned fMRI prediction
- cross-view retrieval between fMRI and stimulus windows
Evaluation
- transfer to Horikawa
- transfer to Emo-FilM
- arousal/valence sanity check
- high-dimensional/component target transfer
- low-level visual/audio control
- feature geometry with emotion rating space
Decision rule
- high-dimensional/component target까지 개선되면 naturalistic pretraining 확장
- arousal나 visual target만 개선되면 sensory adaptation으로 해석
- transfer benefit이 없으면 emotion-specific head, subject adapter, target redesign, alignment 우선
──────────────────────────────
Phase 4. TRIBE v2 + SwiFT Alignment
──────────────────────────────
Goal
stimulus dynamics와 fMRI dynamics를 shared latent에서 정렬합니다.
Candidate architecture
Stimulus path
video/audio/text -> TRIBE v2 or component encoders -> z_stim
Brain path
fMRI window -> SwiFT -> z_brain
Shared latent
align(z_brain, z_stim)
Heads
z_brain -> emotion
z_stim -> emotion
z_stim -> predicted fMRI
z_brain -> future/reconstructed fMRI
Candidate loss
L = emotion loss from brain
  + optional emotion loss from stimulus
  + alignment loss between brain and stimulus
  + optional fMRI encoding loss
  + optional self-supervised fMRI loss
Alignment options
- regression alignment
- contrastive InfoNCE
- CKA/RSA geometry alignment
- JEPA-style cross-view prediction
- synchronized retrieval
Surface/volume mismatch
- SwiFT: volumetric 4D fMRI
- TRIBE v2: cortical surface prediction
First solution
common parcellation or latent-only alignment
Decision rule
- alignment이 high-dimensional emotion 또는 cross-dataset transfer를 개선하면 TRIBE-SwiFT model surgery 우선
- encoding만 좋아지고 emotion은 안 좋아지면 auxiliary로 유지
- stimulus-only가 brain-only를 압도하면 brain-specific residual 분석 필요
──────────────────────────────
Phase 5. Brain-Tuned Affective LLM/VLM Extension
──────────────────────────────
Goal
affective LLM/VLM representation을 fMRI response로 regularize합니다.
Inputs
- affective caption
- cue/rationale label
- appraisal embedding
- VLM/LLM stimulus embedding
- fMRI latent
Candidate model
stimulus -> affective LLM/VLM -> z_affect
fMRI -> SwiFT -> z_brain
align z_brain and z_affect using contrastive / retrieval / RSA-style losses
주의
- 이 track은 stimulus-side representation을 풍부하게 만드는 extension
- fMRI가 직접 reasoning을 한다고 주장하지 않음
- Alignment나 stimulus-side baseline이 유망할 때만 활성화
Task and Metric Design
L0. data/timing sanity
- Dataset: all
- Metric: shape/timing report
L1. arousal regression
- Dataset: Affective Videos, Emo-FilM
- Metric: Pearson/Spearman, CCC
L2. valence regression/category
- Dataset: Affective Videos, IAPS, Emo-FilM
- Metric: correlation, balanced accuracy
L3. discrete/multi-label emotion
- Dataset: Horikawa, Emo-FilM, NeuroEmo
- Metric: macro F1, AUROC
L4. high-dimensional emotion vector
- Dataset: Horikawa, Koide-Majima
- Metric: RSA, CKA, vector correlation
L5. appraisal/component prediction
- Dataset: Emo-FilM
- Metric: target-wise correlation
L6. continuous affect trajectory
- Dataset: Emo-FilM, REELMO
- Metric: time-lagged correlation, CCC
L7. cue/rationale/caption embedding
- Dataset: MLLM/REELMO targets
- Metric: retrieval, contrastive score
Critical controls
- subject split
- stimulus split
- temporal lag sweep
- low-level visual/audio control
- stimulus-only baseline
- ROI/ridge baseline
- frozen vs adapted SwiFT
- generic vs naturalistic-pretrained SwiFT
- cross-dataset test

6. Expected Results
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Expected Pattern 1
Frozen SwiFT shows partial transfer.
예상
- arousal 또는 coarse category에서는 frozen SwiFT가 어느 정도 신호를 보일 수 있음
- high-dimensional emotion vector나 component target에서는 frozen feature만으로 부족할 수 있음
해석
- frozen SwiFT가 일부 generic emotion-relevant structure를 갖고 있으면 adapter/head track이 유망
- frozen SwiFT가 simple baseline보다 나쁘면 preprocessing, HRF timing, readout 설계를 먼저 점검
Expected Pattern 2
Arousal transfers more easily than valence or high-dimensional emotion.
Target difficulty
arousal
- expected difficulty: easiest
- interpretation: generic attention / physiology / salience와 연결
valence
- expected difficulty: harder
- interpretation: stimulus semantics와 appraisal 필요
category
- expected difficulty: medium-hard
- interpretation: label taxonomy와 dataset bias 영향
high-dimensional vector
- expected difficulty: core challenge
- interpretation: rich emotion geometry 필요
component/appraisal
- expected difficulty: hardest but important
- interpretation: context와 interpretation 필요
주의
arousal만 잘 되는 것은 성공이 아닙니다.
high-dimensional target이나 component target에서 개선되어야 emotion representation claim이 강해집니다.
Expected Pattern 3
Naturalistic pretraining may help, but only under strict controls.
성공적인 결과
- naturalistic-pretrained SwiFT > generic/resting SwiFT
- improvement appears on Horikawa and Emo-FilM
- improvement appears beyond arousal
- low-level visual/audio control 후에도 signal이 남음
약한 결과
- movie pretraining이 fMRI reconstruction만 개선하고 emotion transfer는 개선하지 않음
- arousal만 개선됨
- visual-only target에서만 개선됨
해석
- 강한 결과라면 naturalistic pretraining track 확장
- 약한 결과라면 sensory adaptation으로 해석하고 emotion-specific head나 alignment로 전환
Expected Pattern 4
Stimulus-only model may be strong.
Emotion labels이 group-level stimulus annotations이면 stimulus-only model이 강할 수 있습니다.
예상
- Horikawa video stimulus feature만으로도 일부 emotion vector를 예측할 수 있음
- Emo-FilM film stimulus feature가 arousal/component 일부를 설명할 수 있음
중요한 해석
stimulus-only가 강한 target에서 brain-only 성능을 brain-specific emotion representation으로 과대해석하면 안 됩니다.
Brain model의 가치가 강해지는 경우
- brain-only가 stimulus-only보다 특정 target에서 강함
- aligned model이 둘보다 좋음
- brain residual이 subject-specific variation이나 component target을 설명함
Expected Pattern 5
Alignment helps high-dimensional targets more than simple labels.
예상
- positive/neutral/negative 같은 coarse label에서는 alignment 이득이 작을 수 있음
- high-dimensional emotion vector, component target, representation geometry에서는 alignment가 더 유리할 수 있음
이유
- rich emotion representation은 stimulus semantics와 brain dynamics가 함께 필요할 가능성이 높음
- TRIBE-style model은 video/audio/text temporal fusion에 강점
- SwiFT는 observed fMRI dynamics를 담음
- 둘을 shared latent에서 결합하면 richer target에서 이득 가능
Scenario-Based Interpretation
1. frozen SwiFT가 좋음
   - 해석: generic BFM에 emotion signal 존재
   - 다음 방향: adapter/head refinement
2. adapter가 크게 개선
   - 해석: emotion-specific modification 필요
   - 다음 방향: parameter-efficient SwiFT adaptation
3. naturalistic pretraining이 개선
   - 해석: stimulus-locked fMRI dynamics 중요
   - 다음 방향: movie/story pretraining 확장
4. stimulus-only가 압도
   - 해석: label이 stimulus-driven
   - 다음 방향: alignment 또는 residual brain analysis
5. alignment가 개선
   - 해석: emotion은 brain-stimulus shared structure
   - 다음 방향: TRIBE-SwiFT dual encoder
6. arousal만 됨
   - 해석: low-dimensional affect 중심
   - 다음 방향: physiology/dynamic objective
7. 전부 약함
   - 해석: target/preprocessing mismatch 가능
   - 다음 방향: target construction 재검토

Short Team Post Version
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FEELIN는 emotion-labeled fMRI에서 Brain Foundation Model이 emotion-relevant representation을 얼마나 잘 잡는지 확인하기 위해 Dataset x BFM x Task master matrix를 먼저 구축하는 모델 개발 프로젝트입니다.
핵심은 단순 emotion label prediction이 아니라, arousal/valence, discrete emotion, multi-label emotion distribution, high-dimensional emotion vector, appraisal/component, trajectory, cue/rationale embedding까지 이어지는 task ladder에서 어떤 model strategy가 가장 transferable한지를 보는 것입니다.
초기에는 Horikawa, Emo-FilM, Affective Videos, IAPS fMRI, NeuroEmo, Koide-Majima/Nishimoto, REELMO를 dataset axis로 두고, SwiFT, Brain-JEPA, NeuroSTORM, BrainLM을 BFM axis로 두며, binary/regression/multiclass/multi-label/high-dimensional/dynamic/component task 조합을 모두 펼친 표를 채웁니다.
logistic/ridge/ROI/voxel 모델은 statistical floor로만 사용합니다.
HCP movie, CNeuroMod/Algonauts, StudyForrest, Narratives, 101 Dalmatians, stimulus-only video/audio/text model, TRIBE v2는 첫 BFM benchmark 이후 필요할 때 pretraining/control/alignment branch로 사용합니다.
Immediate action은 master matrix 확정, target construction, split/metric policy, statistical floor, frozen BFM probe입니다.
