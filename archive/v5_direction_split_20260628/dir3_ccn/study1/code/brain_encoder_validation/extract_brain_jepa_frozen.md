# Frozen Brain-JEPA Re-extraction

## Why this exists

The original CCN Brain-JEPA embeddings were extracted from a checkpoint pretrained on
`450 x 160` inputs (10 temporal patches) using a `450 x 16` input (one temporal
patch). The old loader averaged the checkpoint's 10 temporal sin/cos codes to obtain
one code.

`encoder.pos_embed_proj.emb_h` is fixed (`requires_grad=False`) sin/cos code, not a
learned positional table. The principled frozen primary condition is therefore
`native`: do not load the mismatched checkpoint tensor and retain the one-patch code
generated by the model constructor. The patch-embedding kernel is 16 TR in both the
checkpoint and the CCN model; this script aborts instead of interpolating it if that
invariant is violated.

This correction removes the arbitrary temporal-code averaging. It does not make a
one-patch input equivalent to the 10-patch pretraining regime. The shorter token
sequence remains an architecture/domain-shift caveat.

## Policies

| Policy | Meaning | Role |
|---|---|---|
| `native` | One-patch position-0 sin/cos code generated by the model | Primary frozen condition |
| `temporal_mean` | Mean of checkpoint positions 0-9 | Exact legacy sensitivity |
| `temporal_center` | Mean of checkpoint positions 4 and 5 | Heuristic sensitivity |

No emotion labels or CCN outcomes are used during extraction. Do not finetune on
emotion labels for the main independent-foundation-model claim.

## Run

Primary, all five subjects:

```bash
sbatch --array=1-5 extract_brain_jepa_frozen.sh native mean
```

Optional center sensitivity:

```bash
sbatch --array=1-5 extract_brain_jepa_frozen.sh temporal_center mean
```

Spatial-only control with corrected position handling:

```bash
sbatch --array=1-5 extract_brain_jepa_frozen.sh native spatial_only
```

Outputs are written only under
`study1/data/brain_encoder_validation/embeddings/`. Full extraction is intentionally
left to the user; Codex only performs syntax and small smoke checks.
