# Code Archive

These files are retained for provenance and are not active pipeline entry points.

| Directory | Contents |
|---|---|
| `legacy_pipeline/` | Numbered scripts that produced or interpreted the accepted-abstract analysis |
| `robustness_checks/` | Reverse-direction, alpha-sweep, and categorical-bias diagnostics |
| `superseded_methods/` | Procrustes, RSA, UMAP, k-sweeps, partial controls, and superseded M1/M2 versions |
| `figure_generation/` | Historical figure generators for accepted and exploratory analyses |
| `extraction/` | Reusable embedding download and extraction utilities |
| `runtime_cache/` | Generated Python cache moved out of the active code surface |

Most archived scripts contain historical absolute paths. Preserve them as records; modernize and promote a method into an active module before rerunning it.
