- 일곱 갈래로 나눠 읽었다.
  - 인용 대조 네 갈래: 문서가 인용한 약 30편을 원문 전문과 공식 코드의 그림·절·표 번호까지 대조했다.
  - 방법과 통계 한 갈래.
  - 자료 사실, 절 사이 일관성, 링크 한 갈래.
  - 문체와 프로젝트 규칙 한 갈래.
- 지적은 모두 136건이다(치명 1, 중대 47, 경미 88).
- 치명·중대 48건은 별도 검증자가 원문을 다시 열어 반박을 시도했다. 결과는 확인 19건, 부분 확인 29건, 반박 0건이다. "부분 확인"은 문제는 실재하지만 심각도나 수정안을 고친 경우다. 아래 수정 문장은 검증자가 고친 판을 따른다.
- 접근하지 못한 원문(호스트 차단)은 맨 끝에 따로 적었다.

## 총평

1. 설계의 뼈대는 결정 기록(a296f382)과 맞고, 대부분의 인용 서술도 원문과 맞는다. 원문과 맞음으로 확인한 서술이 112건이다.
2. 다만 원문을 잘못 전하는 서술이 여덟 곳 있다. 그중 셋은 이 연구에 불리한 선행 결과를 빠뜨린 것이라 심사에서 바로 지적될 수 있다.
   - Gao의 Cowen 프레임 결과.
   - Garcia의 영상 fMRI 결과.
   - Kragel이 Cowen 영상과 영화 fMRI를 이미 썼다는 점.
3. 설계에서 가장 큰 빈칸은 두 가지다.
   - 분석 2의 정서 선택성("선택한 정서가 다른 정서보다 더 떨어진다")에 검정이 없다.

4. 문서가 가정, 예측, 대안 설명을 "가설 1, 2"로 부르는데, 정작 가설 문장이 없다.
5. 12/7까지 계산이 불가능한 항목이 있다. 누적 제거 곡선 전체와, Holm 보정에 필요한 무작위 추출 수다.

## 2. 설계와 통계 보완

### 분석 1

- **"동일 위치"를 정의해야 한다(322, 327행).** 자기지도 checkpoint를 미세조정 클래스에 불러오면 다음이 바뀐다.
  - 학습된 토큰별 norm은 쓰이지 않는다.
  - `fc_norm`은 새로 초기화된다(γ=1, β=0).
  - 열 표준화 ridge라면 이 차이는 편향을 만들지 않지만, 문서에 적어야 한다.
- **판독기 목적함수가 모호하다.** 1단계는 logit에 sigmoid를 쓰는데(326행), 규제 규칙은 4-4의 평균제곱오차 ridge다(301행). 둘 중 하나로 정한다.
- **VideoMAE 표 11과 절차가 다르다.** 표 11은 SGD 선형 판독(lr 0.1, 100 epoch)이다. 우리 절차는 다르다고 적는다.
- **미세조정 모델 쪽 판독기는 그 encoder가 학습한 영상으로 적합된다.** 두 checkpoint 사이에 비대칭이 생긴다. 학습 영상과 검증 영상에서의 판독 r을 함께 보고하고, 검증 영상으로 적합한 판독기를 보조로 둔다.
- 제안 문장(327행): "두 checkpoint 모두 미세조정 모델 클래스에 불러 마지막 블록 출력의 토큰 평균에 affine 없는 LayerNorm을 적용한 768차원 벡터를 쓴다. 판독기는 VCE 학습 영상으로 열을 표준화한 ridge(평균제곱오차)이며 출력에 sigmoid를 적용하지 않는다. 규제는 VCE 검증에서 고른다. VideoMAE 보충 표 11의 SGD 선형 판독 절차와는 다르다."

### 분석 2 (가장 중요)

- **정서 선택성 검정이 없다(56, 121, 295, 349행).**
  - 확인적 검정군은 "자기 정서 상위 head 대 같은 층 무작위" 27개뿐이다. 이것은 27개 정서가 모두 똑같이 떨어져도 성립한다.
  - 27×27 행렬도 원 Δr이라, 행 안의 비교가 정서별 기준 r 차이와 평정 간 상관(공포, 공포감, 불안)에 섞인다.

### 통계(4-4)

- **Holm 검정군과 계획한 무작위 추출 수가 맞지 않는다.**
  - 몬테카를로 p의 최소값은 1/(n+1)이므로, Holm 첫 임계값 α/m에 이르려면 n ≥ m/α − 1이 필요하다.
  - 분석 2(m=27)는 539회, 분석 6(m=54)은 1,079회, 분석 5(13묶음 × 27, m=351)는 7,019회다.
  - 303행이 "부족하면 효과 크기와 구간만"이라고 열어 두었으므로 설계 오류는 아니다. 다만 비용이 계산되지 않았다.
- **검정군을 줄인다.**
  - 분석 2: 선택성 단측 검정 하나.
  - 분석 5: head 단위 검정과 신뢰도 기준 통과 묶음 대비.
  - 분석 6: 뇌 경로 r > 0 검정 27개(시험 fold 안 표적 치환, 추출 수 제한 없음).
  - 선택 대 무작위는 짝지은 영상 bootstrap 구간으로 보고하고, 무작위 순위 p는 기술값으로 둔다.
- **추론 범위를 명시한다.** "검정은 참가자별 고정효과이며 영상에 대한 일반화다. 같은 부호를 보인 참가자 수를 함께 보고한다." 5명이면 양측 부호검정의 최소 p는 0.0625다.
- 대비마다 단측과 양측을 미리 적는다. 분석 6의 뇌 경로 r > 0 검정은 지금 어느 검정군에도 없다.
- 여섯 fold 모델의 시험 예측을 모아 한 번에 상관을 구하면 fold별 절편이 더해진다. 보조로 fold별 상관의 평균도 보고한다.
