## 1. 연구

- EmoBrain은 석진 님의 석사 학위논문이다. 시각 자극을 볼 때의 fMRI 반응에서 34개 범주의 정서를 decoding하고, 그 정서 관련 뇌 반응이 장면의 시각적 특성과 의미에 어떻게 연결되는지 묻는다.
- 모델 논문이 아니다. 정서 신경과학 질문이 먼저이고, 모델은 그 질문에 답하는 도구다.
- 질문
    - 질문 1(정서 신경과학): 시각 자극을 볼 때 나타나는 정서 관련 뇌 반응은 장면의 시각적 특성과 의미에 어떻게 연결되어 있는가?
    - 질문 2(모델): 장면 정보와의 연결을 학습에 활용하면, 뇌만으로 정서 점수를 예측하는 방식은 어떻게 달라지며, 처음 보는 장면에서는 어떤 정보를 이용해 예측하는가?
    - 목표: 영상과 캡션 없이 뇌 반응만으로, 그 사람이 본 장면의 정보와 그 장면이 사람들에게 일으키는 정서를 읽는다.
- 일정: 결과 11/18, 심사 12/15.
- EmoBrain(학위논문)과 CCN은 별개 프로젝트다.

## 3. 고정 사실

- 자료: Horikawa 외(2020)의 5명(HK), 분석 영상 2,181개. MindCaptioning(Horikawa, 2025) 자료는 MC라고 부른다.
- MC 최종 시험 영상 72개와 그 중복 영상은 HK 개발의 모든 단계에서 뺀다. 학습, 설정 선택, 표준화, Stimulus Model, 내용 구역, 짝이 모두 해당한다.
- MC 시청 자료로 HK 공유 모델의 전이를 평가한다. 회상 자료는 필수 실행 범위 밖이고, 하게 되면 탐색적 보조 분석이다.
- 정서 범주는 34개다. 27개로 줄이지 않는다.
- 34개 값은 그 범주에 "예"라고 답한 평정자의 비율(0~1)이다. 1~9점은 14개 정서 차원이고, 뇌 모델 학습에는 쓰지 않으며 보조 분석(01의 B4, K1a)에서만 다룬다.
- 정답은 스캔 참가자 본인이 아니라 다른 사람들이 매긴 규범 평정(normative ratings)이다. 주장은 "뇌 반응에 그 장면이 사람들에게 일으키는 정서에 대한 정보가 있다"까지다. 참가자가 실제로 느낀 정서를 주장하지 않는다.
- 시험 때 뇌 모델의 입력은 뇌 반응뿐이다.
- 신규성으로 주장하지 않는 것
    - 세밀한 정서 decoding: ML-BVAE(Fu 외, 2024)
    - 34차원 연속 회귀: GED(Huang 외, 2022)
    - 정서 학습의 distillation: AESL(Fu 외, 2025)
    - LLM 사용: EmoMind(Mohammed 외, 2026)
    - 시각 특징과 캡션 특징을 함께 쓰는 것 자체
    - brain token과 학습하는 query로 특징을 맞히는 구조: Brain-IT(Beliy 외, 2026)
    - 신규성 문장은 01의 A4를 따른다.

## 4. 결정 규칙

- 우리 결과를 뽑아 비교해서 설계를 고르지 않는다. 선행 논문이 같은 자극에서 고른 것을 따르는 것은 근거로 인정한다.
- 결과를 보고 설계를 바꾸는 조건부 규칙을 쓰지 않는다. 조건은 미리 정하고, 결과에 따라 주장 범위만 조정한다.
- 시험 fold는 설정 선택, 조기 종료, 표준화, Stimulus Model 학습에 쓰지 않는다.
- 모든 결정에는 선행 연구의 근거와 이유를 단다. 근거를 대지 못하는 방법과 숫자는 쓰지 않는다.
- 결과 수치에 영향을 줄 수 있는 값은 Claude Code가 혼자 정하지 않는다. ex) 후보값, 선택 기준, 전처리

## 6. 답하는 방식

- 긴 답을 하기 전에 무엇에 답하는지 한 문장으로 세우고, 결론을 먼저 쓴다.
- 주제가 바뀔 때는 [1], [2] 같은 표시로 구분한다.
- 소제목은 하고 싶은 말을 문장으로 쓴다. 한 문장에는 한 가지 생각만 담는다.
- 피드백은 "반드시 고칠 것"과 "보완하면 좋은 것"으로 나눈다. 재료를 나열하지 말고 핵심 질문 아래로 묶는다.
- 문장을 고쳐 줄 때는 변경 전과 변경 후를 나란히 보여 준다.
- 사실(데이터셋, 수치, 출판 여부, 방법)은 원문이나 웹으로 확인한다. 확인하지 못한 것은 확인하지 못했다고 쓴다. 추측을 사실처럼 말하지 않는다.
- 석진 님의 생각이 틀렸다고 판단되면 근거를 들어 고친다. 무조건 따르지 않는다.
- GPT, Gemini, Claude 대화의 의견도 근거로 판정한다. 맞는 결론과, 거기서 바로 나오지 않는 결론을 나눠 쓴다.
- 석진 님이 설명하려고 든 예시를 실제 분석 항목으로 문서에 적지 않는다.

## 7. 글쓰기 규칙

- 쉬운 한국어로 쓴다. 추상 명사와 은유 대신 실제 대상과 조건을 쓴다. ex) "장면이 바뀔 때" 대신 "처음 보는 종류의 장면"
- 번역투를 쓰지 않는다. 한국어로 읽어 어색한 표현을 고친다.
- 예시는 ex)로 단다. 문헌은 문단이 아니라 표나 불렛으로 하나씩 쓴다.
- 불렛은 들여쓰기 단계를 살려 쓴다.
- 쓰지 않는 것: em dash, 가운뎃점, "잰다", "가른다", "몫"(활용형 포함). "증류" 대신 distillation.
- 명확한 영어 기술 용어는 영어로 쓴다. ex) ridge, block, decoder, encoder, head, fold, seed, soft BCE, feature decoding, decoded features
- 인용은 정확한 APA 저자-연도로 쓴다. 방법이나 자료 이름만으로 인용하지 않는다. ex) "(MindCaptioning)" 대신 "(Horikawa, 2025)"
- 용어
    - 개념은 "시각 정보"와 "의미 정보"다. 의미 정보를 풀어 쓸 때는 "상황"이라고 쓴다.
    - 측정치는 출처로 부른다. "시각 특징"은 시각 모델에서 뽑은 것, "캡션 특징"은 사람이 쓴 캡션을 언어 모델로 바꾼 것이다. "영상 특징", "의미 특징"이라고 쓰지 않는다.
    - "맥락"을 공식 용어로 쓰지 않는다.
    - 이 연구의 정서는 "시각 자극이 일으킨 정서(visually evoked emotion)"다.
    - 모델 이름(뇌 모델, Stimulus Model, Feature Extractor)과 역할 이름(teacher, student)을 섞지 않는다.
    - 다섯 학습 조건: Brain → Emotion, Brain → Emotion [distillation], Brain → Emotion + Vision + Caption, Brain + Decoded Feature → Emotion, Brain + Decoded Feature → Emotion [distillation]. thesis의 영어 이름은 01의 1-1을 따른다.
    - Horikawa 외(2020)의 의미 이름표는 "이름표 73개"라고 부른다.
- 문서 소제목은 관례적인 학술 절 이름을 쓴다. 은유적인 제목이나 새로 만든 줄임말을 쓰지 않는다.
