## 2. 결과 반입 때 확인할 항목과 11/17 분석 범위

### 2-1. 결과 수령 후 확인할 네 가지

1. S10 6-2 구역 통계와 [사전] 15개 Holm 결과
   - 60개 학습 완료 기록과 pride 규칙을 유지한다. s10_zone 및 s10_holm15의 실제 출력·실행 manifest를 받아 mean5와 sub-01~05 각각의 15개 가설을 확인한다. 실행 완료 기록은 아직 확인하지 못했으며 누락 시에만 담당자와 잔여 과업을 정한다.
2. S6 조건별 실행·선택·병합 provenance
   - [사전] 2-3(다)는 A-2 vs A-1, 2-3(바)는 C-2 vs C-1이다. A-2·C-2 결과는 사전 검정으로 보존하고 D-2는 SI로 둔다. D-1·D-3·D-4의 후속 사용 기록과 조건별 완료 manifest를 대조하되, 현재 미완료 학습이 있다고 가정하지 않는다.
3. S8 6-4a 네트워크 출력과 완료 manifest
   - [사전] 1-3의 Visual1·Visual2·Default 검정은 Holm15의 필수 입력이다. s10_network 출력과 13묶음·6 fold·2조건의 manifest를 확인한다. 계획 156회와 실제 완료 수를 구분하며, 결과 수령 전에는 새 GPU 분담을 확정하지 않는다.
4. MC 시청 확장·회상 및 6-4e 탐색 결과표
   - 완료 기록이 있는 MC B-1/D 확장, MC 회상, 6-4e와 개인 모델 비교의 결과표·설정·제외 목록을 받는다. MC 전이는 참가자 입력층을 학습한 뒤의 데이터 전이이며, 두 자료의 영상 모음이 겹치므로 적응 없는 새 참가자·완전히 다른 영상 일반화로 쓰지 않는다. 규준 영상 평정으로 회상 중 주관적 정서 경험을 단정하지 않는다.

### 2-2. 11/17 확정 결정과 추가 실행 경계

1. Distillation 추가 사용 종료와 teacher 한계
   - A-2·C-2·D-2를 더 학습하거나 후속 분석에 확장하지 않는다. A-2·C-2는 [사전] 결과로, D-2는 SI로 보고한다. S4 teacher가 같은 특징의 Ridge보다 낮았다는 한계는 A-2·C-2와 K1 해석에 남긴다. E의 기존 결과도 보존하되 이후 분석·MC에는 쓰지 않는다.
2. 27개 정서판 해석과 기존 34개 사전 검정 분리
   - 학습은 기존 34개판을 유지한다. 11/17 이후 해석·추가 분석은 pride, triumph, contempt, disappointment, sympathy, guilt, envy를 뺀 27개판으로 하며 저장 예측을 사용하고 재학습하지 않는다. 이미 시행한 34개 [사전] 검정은 그대로 보고하고, Holm15 실제 실행 여부는 별도로 확인한다.
3. 깊이·시드·보조 조건의 실제 실행 기록 확인
   - 2-block은 완료 기록이 있고, 이후 01 6-4e에는 depth4 CKA 비교도 기록돼 있다. 따라서 4-block을 일괄 미실행으로 두지 않고 manifest를 받는다. D-3 짝은 현재 후속 모델 집합에 포함되며 MC 회상은 완료 기록이 있는 탐색 분석이다. 추가 seed 1,2 등 새 학습은 자동 실행하지 않고 확인된 잔여 과업만 분담한다.
