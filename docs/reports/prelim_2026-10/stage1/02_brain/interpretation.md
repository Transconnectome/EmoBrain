# 핵심 3: 현재 전처리의 뇌 단독 정서 기준선 (Horikawa, 2026-10-24)

**Question:** 현재 전처리(v3_qc)의 뇌 반응만으로, 같은 피험자가 처음 보는 영상의 정서 평정 차이를 어느 정도 예측하는가? 어떤 차원에서 어렵고, 단순한 대안 입력과 비교하면 어떤가?

**Why?:** 후속 학습(외부 정보 보조 학습 등)이 개선할 기준을 현재 task 에서 정한다. 예전의 "뇌 단독 성능 부족" 판단을 현재 입력으로 다시 확인한다.

**Input:** Horikawa sub-01~05. 469개 영역 평균(run 안 z, 유효 영역 467~469개). A34(34개 범주 비율)와 A14(14개 척도, 관측 영상만). 분할 `horikawa_rungroup6_v1`. 계약은 `../01_task/task_contract.yaml`.

**Analysis:** 피험자별·차원별 독립 선형 모델. A34 는 L2 선형 sigmoid + soft BCE, A14 는 ridge. 규제 강도는 차원마다 안쪽 5겹 검증 손실로 골랐다. 같은 평가 영상에서 기준선 넷(train 평균, 영상 길이 구간, 저수준 시각 33개, 뇌 전체 평균·신호 크기)을 같은 절차로 학습했다. 지표는 6개 fold 의 평가 예측을 모은 차원별 Pearson r, train 평균 대비 오차 감소율, 영상별 프로필 상관이다.

**Figure:** `../figures/fig_core3_dimension_r.png` (차원별 r, 5명 범위, 기준선 비교).

**결과:**

- 48개 차원 모두에서 뇌 r 가 5명 전원 0보다 크고, 48개 모두에서 저수준 시각 기준선보다 높다.
- A34 상위: sexual desire 0.66, aesthetic appreciation 0.54, disgust 0.53, entrancement 0.50, amusement 0.47, fear 0.47, anxiety 0.47. 하위: guilt 0.07, envy 0.08, contempt 0.11, pride 0.15.
- A14 상위: safety 0.48, control 0.46, valence 0.44. 하위: dominance 0.20, arousal 0.26, attention 0.28.
- 감정별 뇌 r 는 높은 점수 영상 수(Spearman +0.85), 라벨 신뢰도 추정(+0.76), 저수준 시각 기준선 r(+0.80)과 순위가 비슷하다.
- 점검: 뇌 조건의 fold 합친 r(0.329)와 fold 별 r 평균(0.335)이 거의 같다. train 평균 예측의 합친 r 가 -0.04 인 것은 fold 마다 평균이 달라 생기는 알려진 효과이며 fold 별로는 정의되지 않는다(상수). 뇌 조건에서 선택된 규제 강도는 격자 끝에 걸리지 않았다.

**해석:**
- 현재 입력과 선형 readout 으로 뇌 반응은 외부 평정자의 영상별 정서 평정 차이를 일관되게 예측한다. 영상 길이와 뇌 전체 신호 크기라는 지름길로는 설명되지 않는다(두 기준선은 거의 0).
- 이것이 "정서 고유 신호"라는 뜻은 아니다. 잘 읽히는 감정은 내용이 분명하고(sexual desire, disgust, craving) 저수준 시각으로도 일부 예측되는 감정과 겹친다. 뇌가 본 영상 내용을 거쳐 평정을 맞혔을 가능성이 크며, 이는 핵심 4·5(V/S → 정서, 뇌 → V/S)로 구분해야 한다.
- 어려운 차원은 높은 점수 영상이 적고 라벨 신뢰도가 낮은 감정(guilt, envy, contempt)과 영상 간 차이가 작은 척도(dominance, arousal)다. 이 차원의 낮은 r 를 뇌 정보 부재로 해석하지 않는다.
- 예전의 "뇌 단독 성능 부족" 판단과는 task·분할·전처리가 달라 직접 비교할 수 없다. 현재 기준선은 "부족"으로 보기 어렵다. 따라서 후속 학습의 목표를 "낮은 성능의 구제"로 잡기보다, 어려운 차원과 내용 의존성(다른 내용 집단 일반화)을 겨냥하는 쪽으로 다시 정할 필요가 있다.
- 입력은 영역 평균이다. voxel 패턴, ROI 단독(편도체·시각 피질), 비선형 모델은 아직 보지 않았다.
