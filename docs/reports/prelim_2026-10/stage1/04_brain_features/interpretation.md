# 비교 사다리: 내용 → 정서, 뇌 → 내용, 뇌 → 내용 → 정서, 뇌 + 내용 → 정서 (Horikawa, 2026-10-24)

**Question:** 뇌가 정서 평정을 맞히는 능력은 영상 내용 정보와 얼마나 겹치는가?

**Input:** 469개 영역 평균(5명), 특징 3종 (저수준 시각 33, Horikawa 시각 1000 = VGG19 fc8, Horikawa 의미 73 = 사람 annotation). 분할·모델·선택 절차는 기준선과 같다.

**Figure:** `../figures/fig_ladder.png`

**결과 (A34 는 27개 기술 요약 평균, A14 는 14개 평균, 5명 평균):**

"내용만" 행은 `03_stimulus` 의 영상 단위 결과(평가 영상 2,181개)다. 다른 행은 피험자별 뇌 QC 통과 행(A34 2,070~2,180개)이라 학습·평가 영상이 다르다. 같은 행 비교는 `content_ladder.py --sub` 재실행 후 `ladder_same_rows_summary.tsv` 로 바꾼다.

- 뇌 → 내용: 시각 1000 열별 r 평균 0.35, 의미 73 0.27, 저수준 0.30. 영상 짝 구별 0.82 (시각·의미), 0.63 (저수준).
- 뇌 + 의미가 의미만보다 높은 차원: A34 27개 중 7개(최대 +0.03, surprise·confusion·fear·awkwardness·anxiety 등), 5명 모두 높은 차원 2개. A14 는 0개.

**해석:**
- 뇌에서 예측한 의미 특징을 거친 정서 예측은 뇌 직접 예측과 비슷한 r 를 보였다 (27개 평균 0.348 대 0.375 로 약 93%, 34개 평균 약 95%, A14 약 99%). r 의 비율이며 공유 정보나 설명 분산의 비율이 아니다. 이 경로의 정서 모델은 학습 영상의 실제 의미 특징과 라벨을 보고 학습한다. 평가 영상에서만 뇌 예측 특징을 쓴다. 정서 고유 정보의 부재나 생물학적 매개 경로를 보인 분석은 아니다.
- 뇌 + 의미 73 이 의미 73 만보다 높지 않았다. 다만 두 행의 영상 집합이 다르고, 결합 모델은 규제 강도 하나를 쓴다. 뇌의 추가 가치에 대한 판단은 같은 행 비교와 결합 방식 점검 뒤로 미룬다. 시각 1000 에 뇌를 더하면 +0.06 이었다(같은 이유로 같은 행 비교에서 다시 확인).
- 주의 1: 의미 73 은 사람(평정자 12명)이 영상에 붙인 개념이라 "자극" 정보이면서 사람 판단이다. 정서 판단과 겹치기 쉽다. V-JEPA·caption 문장 모델 같은 기계 표현으로 다시 확인해야 한다.
- 주의 2: 뇌 + 내용은 이어 붙인 입력에 규제 강도 하나를 쓴다. 뇌 쪽의 추가 기여를 과소평가할 수 있으므로 입력 묶음별 규제(banded ridge)나 잔차 방식으로 보완한다.
- 주의 3: 입력은 영역 평균이다. voxel 패턴에서는 내용 밖 정보가 더 보일 수 있다.
