# 학습 곡선 (Horikawa, 469개 영역 평균, 2026-10-24)

**Question:** 학습 영상 수를 줄이면 뇌 → 정서 예측이 얼마나 떨어지나? (한국인 재현 실험의 영상 수 결정 근거)

**Analysis:** 같은 평가 영상(바깥 fold)에서 학습 영상을 run 째로 무작위로 줄임 (150~1500개 목표, 반복 4번, 작은 학습량 ⊂ 큰 학습량). 'all' 은 기준선과 같은 조건이며 기준선 값(A34 0.329, A14 0.361)을 재현했다.

**Figure:** `../figures/fig_learning_curve.png`

**해석:** 600개 전후에서 80%, 900개 전후에서 90% 를 넘는다. 1,800개에서도 곡선이 아직 조금 오르고 있어 포화되지는 않았다. 시험용 영상(반복 포함)은 따로 더해야 한다. 장비·TR·참가자가 다른 새 실험에 그대로 옮겨지는 숫자는 아니며, 영역 평균 입력 기준이다. 영상 고르는 방법(무작위 영상, 감정 균형, 평정 합의 우선)의 비교는 다음 분석이다.
