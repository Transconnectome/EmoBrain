# EmoBrain 평가 분할과 피험자 처리 규칙

_2026-10-22 확정 (사용자 결정). 기존 무작위 분할은 삭제했다._

## 현재 분할: `horikawa_rungroup6_v1`

- 파일: `horikawa_rungroup6_v1.tsv` (영상 2,196행), 요약 `horikawa_rungroup6_v1.json`
- 생성 코드: `/storage/bigdata/EmoBrain_response/code/splits/make_horikawa_split.py`
- 대상: Horikawa 2020 (주 데이터) 5명. MindCaptioning(재현) 분할은 재현 단계에서 같은 규칙으로 따로 만든다.

| 규칙 | 내용 |
|---|---|
| 나누는 대상 | **영상**. 단, 영상 하나씩이 아니라 **run 단위로 묶어서** 나눈다 |
| run 의 정의 | 사람 간 공통인 `run_index`(0~60, 시간 순서). 5명이 같은 61개 run 을 같은 순서로 봤다. 세션 이름(ses/run)은 사람마다 경계가 달라 쓰지 않는다 |
| 같은 내용 쌍 | 같은 `content_id` 두 영상이 든 run 들은 하나로 묶어 같은 fold 에 둔다 (61개 run → 46개 묶음) |
| 바깥 분할 | 6 fold, 분석 영상 357~393개씩 (라벨을 보지 않고 영상 수만 맞춤) |
| 안쪽 분할 | 설정(정규화 강도 등) 선택은 바깥 학습 fold 5개를 그대로 5겹으로 쓴다 |
| 피험자 간 | **모든 피험자에게 같은 분할을 쓴다.** 어떤 영상이 평가 fold 에 있으면 5명 모두에서 그 영상은 평가용이다 |

검증: 한 run 이 두 fold 에 걸친 경우 0, 같은 내용 쌍이 갈린 경우 0.

## 피험자 처리 규칙 (기준선 단계)

| 질문 | 규칙 | 이유 |
|---|---|---|
| 분할 단위가 피험자인가? | 아니다. 영상(run 묶음) 단위다 | 지금 묻는 일반화는 "같은 사람이 처음 보는 영상"이다 |
| 모델을 피험자마다 따로 학습하나? | **그렇다. 피험자별 모델 5개** | 뇌가 각자의 개인 공간이라 voxel 수·위치가 다르다. 라벨은 영상별 외부 평정이라 5명을 합쳐도 같은 정답이 5번 반복될 뿐이다. 원 논문도 피험자별 |
| 평가는? | 피험자마다 6개 fold 의 평가 예측을 모아 감정별 r 등을 계산. 5명의 값을 따로 보존하고 평균·범위로 요약 | 다른 사람의 예측을 이어 붙여 하나의 r 로 만들지 않는다 |
| 피험자를 섞은 모델은? | 기준선에서는 하지 않는다. 469개 영역 평균은 사람 간에 같은 영역이라 기술적으로 가능하므로, 필요하면 후속 비교(공통 모델, 집단 평균 뇌)로 둔다 | 같은 분할을 쓰므로 나중에 섞어도 평가 영상이 학습에 들어가지 않는다 |
| 다른 사람으로의 일반화는? | MindCaptioning 재현 단계의 별도 질문 | 지금 범위가 아니다 |
