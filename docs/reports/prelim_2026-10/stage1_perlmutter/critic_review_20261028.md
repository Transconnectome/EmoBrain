# 독립 검토: "뇌 디코딩은 대부분 장면 의미 디코딩" 주장 (2026-10-28)

검토자: 독립 critic agent (결론 없이 결과 파일·설계 문서·주의 기록만 받음). 판정: **Revise**.
방향("뇌로 읽히는 평정 정보가 내용 모델이 잡는 부분에 몰려 있다")은 단순 기대치보다 강해 맞을 가능성이 높지만, 표현이 증거를 넘는다.

## 받아들인 지적

1. **target 이 영상의 속성이라 "정서 고유 대 장면 의미"는 식별되지 않는다.** 잔차는 "정서 고유 신호"가 아니라 "이 teacher 가 설명하지 못한 자극 정보"다. 질문은 "현재 영상·캡션 모델 대비 뇌가 선형으로 더 접근 가능하게 하는 자극 정보"로 모델 상대적으로 바꾼다.
2. **"scene-semantic" 이라는 이름은 설계 문서(01 §1 "말하지 않을 것")가 금지한 이분법이다.** "내용 모델이 예측하는 성분"으로 부른다. 사람 캡션은 다른 사람의 해석(appraisal 포함)이다.
3. **결합(fusion)이 실패하고 있다.** 뇌 + 캡션 < 캡션, 뇌 + 의미 73 < 의미 73 (5명 모두), V-JEPA 2 + 캡션 teacher(0.591) < 캡션만(0.605). 규제 강도 하나로 이어 붙인 결합의 결함이라 "뇌가 캡션에 더하는 것이 없다"는 아직 근거가 없다.
4. **82% 분해에 비교 기준(null)이 없다.** "설명 가능한 평정 신호를 고르게 읽는" 기대치는 약 46~49% (R²_teacher / 신뢰도, critic 의 즉석 계산)라 관측치가 높지만, 같은 파이프라인을 거친 가짜 뇌로 확인해야 한다.
5. **"transmodal 에 국소화"는 과장이다.** 시각 8.6% → Default 17% 의 1.5~2배 경사일 뿐이고, 14개 차원에서 가장 큰 곳은 그 밖 피질하다. 묶음 크기를 맞추지 않았고, teacher 에 V-JEPA 2 가 있어 시각 잔차가 작은 것은 구성상 당연하다.
6. **Horikawa 2020 의 encoding 결론(transmodal 영역에서 정서 범주 모델이 시각·의미 모델보다 낫다)과 부딪힌다.** 우리 decoding 몫은 다른 양이다. 같은 방식의 encoding 분산 분할이 필요하다.
7. **teacher–student 이득은 target denoising 처럼 행동한다.** 이득이 teacher 정확도에 비례하고, 라벨 smoothing 이 이득의 약 40% 를 내며, 시각만 쓴 teacher 는 라벨 smoothing 과 비슷하고, MAE 는 나빠진다. 내용 접근·모델 사용 검정 전까지는 학습 전략으로만 다룬다.
8. **"뇌 → 캡션 → 정서 = 뇌 직접" 은 진단력이 낮다.** 768차원 중간 공간은 병목이 아니고, 다출력 회귀의 정규화 효과로 경유가 오히려 높을 수 있다.
9. **한국인 평정의 진단력을 과대평가했다.** 한국–미국 평정 차이도 영상의 속성이라 한국 평정으로 학습한 내용 모델이 배울 수 있다. "참가자 뇌가 어느 평정 집단의 규범에 더 맞나"라는 별도 질문으로 사전 등록할 때만 의미가 있다.
10. **정정:** Horikawa 2020 은 참가자 국적을 밝히지 않았다 (ATR 교토에서 촬영, 성별·나이만 기술). 앞서 "일본인"이라고 한 것은 확인하지 않은 말이었다.

## 수정한 주장 문안 (critic 제안 기반)

Horikawa(2020) 자료에서 영역 평균 뇌 반응으로 규범 정서 평정을 예측할 때 쓰이는 정보는 현재 영상·캡션 모델이 같은 영상에서 추출하는 정보와 대부분 겹친다. 뇌 디코딩의 약 80% 가 내용 모델 예측과 공변하며, 이는 설명 가능한 평정 신호를 고르게 읽는 디코더의 기대치보다 높다. 나머지는 내용 모델이 평정 신뢰도에 비해 약한 범주에서 크고, 시각에서 transmodal·피질하 묶음으로 갈수록 완만히 커진다. 규범 target 은 자극의 속성이므로, 이 결과는 현재 모델 대비 뇌가 선형으로 접근 가능하게 하는 자극 정보의 범위를 말할 뿐 정서 고유 처리의 유무를 판정하지 않는다. 내용 안내 학습의 작은 이득은 target denoising 과 같은 양상이므로, 내용 접근·모델 사용 검정을 통과할 때까지 학습 전략으로만 다룬다.

## 다음 분석 (critic 순위, 실현성 × 진단력)

1. 결합 재실행: 묶음별 규제(banded ridge) 또는 교차검증 밖 stacking 으로 뇌 + 캡션, 뇌 + 의미 73, V-JEPA 2 + 캡션 teacher. 가장 강한 내용 예측의 잔차와 뇌 예측의 부분 상관.
2. 분해의 null 보정: 해석적 기대치와 같은 파이프라인을 거친 가짜 뇌 두 가지 (열화한 내용 특징, 평정 + 잡음을 469차원에 투영).
3. encoding 쪽 분산 분할: 영역별로 내용 특징 대비 평정의 고유 설명분산 (Horikawa 2020 과 같은 방식).
4. 신호대잡음 곡선: 같은 영상에 대한 k = 1~5 명 반응 평균으로 내용/잔차 몫 재계산.
5. teacher 사다리와 묶음 크기 맞춤, voxel 수준 반복, 잔차의 교란 회귀 (FD, 전역 신호, 길이·밝기·움직임).
