# 같은 대상(맥락) 안에서 저수준 특징이 정서를 가르나 (2026-10-31, 자극 수준)

코드: `perlmutter/within_context_lowlevel.py` · `.sh`. 맥락은 Horikawa 의미 73 개념 묶음의 최댓값 ≥ 0.5 인 영상 (음식 86, 동물 524, 피·상처·배설물 165, 자연·풍경 297, 노출·성 164, 아기 76, 스포츠·묘기 239, 탈것 134).
맥락마다 10겹 교차검증 ridge 로 정서를 예측한 r. 저수준은 `features/build_lowlevel_motion.py` 28개 (색·밝기·선명도·움직임). 유의성은 맥락 안에서 정서를 섞은 null 200회.

| 파일 | 내용 |
|---|---|
| `model_r.tsv` | 맥락 × 감정별 r: 저수준, 캡션 (정서어 지운 캡션), 캡션 뒤 저수준, CLIP, V-JEPA 2, 그리고 null p |
| `feature_corr.tsv` | 맥락 × 감정 × 저수준 특징 28개의 상관 |

## 결과

- 같은 맥락 안에서도 저수준만으로 정서가 꽤 읽힌다 (32개 중 21개 p ≤ 0.05). 자연·풍경의 aesthetic appreciation r 0.50, calmness 0.47, awe 0.30; 피·상처의 disgust 0.38; 노출·성의 sexual desire 0.22 (갑작스럽지 않고 고른 움직임일수록 높음, motion_peakiness r −0.35), romance 0.38; 스포츠·묘기의 fear 0.26.
- 해석 가능한 방향: 자연에서는 움직임이 적을수록 aesthetic appreciation·calmness 가 높고 (r −0.39), 노출·성에서는 고른 움직임일수록 sexual desire 가, 어둡고 색이 적을수록 romance 가 높고 (어두운 화소 비율 r +0.42), 여러 맥락에서 채도·색감이 낮을수록 fear 가 높고, 따뜻한 색이 많을수록 disgust 가 높다 (음식 +0.31, 피·상처 +0.32, 동물 +0.21).
- disgust·fear 의 주요 저수준 상관은 맥락마다 방향이 같다. 방향이 바뀌는 특징 (disgust 의 밝기·선명도·가장자리 밀도) 도 있지만 크기가 0.15~0.24 로 작다. 앞선 쌍 분석이 0 이었던 주된 이유는 방향 상쇄가 아니다.
- 캡션이 설명하고 남은 정서를 저수준이 설명하는 경우는 32개 중 2개 (음식 amusement r 0.20 p 0.035, 자연 calmness 0.06 p 0.04) 로, 우연 기대 (약 1.6개) 와 비슷하다. 같은 맥락 안에서도 저수준이 가진 정서 정보는 캡션에 이미 있다.
- 캡션은 색 단어 9.7%, 빛 단어 2.7%, 속도 단어 4.5% 로 저수준을 직접 말하는 경우가 적다. 저수준과 캡션이 겹치는 것은 저수준 단서가 서술된 내용과 함께 움직이기 때문 (붉은색 = 피, 어두운 조명 = 침실 장면) 으로 본다. 색 자체와 그 색이 가리키는 대상을 이 자료로는 떼어 낼 수 없다.
