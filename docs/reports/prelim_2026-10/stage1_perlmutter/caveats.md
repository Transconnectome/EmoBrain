# Perlmutter 1단계 후속 분석: 해석 주의 기록 (2026-10-28)

결과 파일은 `project/output/prelim_2026-10/` (git 밖). 코드는 `project/analysis/prelim_2026-10/perlmutter/`. 아래 항목은 결과를 쓸 때 함께 밝힌다.

## 감정 범주

- **guilt, envy, contempt.** 라벨 신뢰도가 가장 낮고(0.28, 0.32, 0.33) 높은 점수 영상이 적다(guilt 113, envy 175, contempt 243개, 5명 평균). 뇌 단독 r 은 0.07~0.11 이다. Horikawa 2020 도 이 세 범주는 5명 모두에서 유의하게 예측되는 영역이 없었다고 보고했다.
  - soft BCE student 의 이득은 이 범주들에서 크다(+0.040~+0.046). 그러나 ridge 대조에서 guilt 의 라벨 smoothing 이득(+0.067)이 내용 teacher 이득(+0.032)보다 컸고, envy 도 대부분 라벨 smoothing 으로 나왔다(+0.037 대 +0.042). MLP 에서 내용 teacher 가 라벨 smoothing 보다 더한 부분은 guilt +0.019, envy +0.011 로 작다.
  - 따라서 이 범주들의 이득과 패턴은 라벨 잡음과 희소성의 영향이 크다. 범주별 결과로 해석하지 않는다.
- **pride, disappointment** 도 신뢰도 0.53, 0.49, 높은 점수 영상 141, 272개로 비슷한 주의가 필요하다.
- **범주별 이득 순위는 자료 특성을 크게 반영한다.** soft BCE 이득은 뇌 단독 r(순위상관 −0.70), 라벨 신뢰도(−0.62), 높은 점수 영상 수(−0.38) 와 관련되고, 이 셋으로 이득 순위 분산의 약 55% 가 설명된다. 내용 특이적 이득(MLP 내용 teacher − 라벨 smoothing)은 이 특성들과 약하게만 관련된다(−0.15~−0.36).

## 영상

- 영상별 이득의 피험자 간 상관은 0.08 로 낮다. 개별 영상 예시는 설명용으로만 쓴다. 5명 모두 좋아진 영상 수(167)는 독립 가정의 기대치(163)와 같고, 5명 모두 나빠진 영상(75)은 기대치(20)의 약 4배다.

## 뇌 영역

- 편도체(4개 영역), 해마(8), 시상하부·뇌간(3)의 뇌 단독 예측은 r 0.01~0.05 로 거의 0 이다. 이 묶음의 내용/잔차 비율은 해석하지 않는다. 묶음 크기(3~93개 영역)가 성능에 영향을 준다.
- Limbic(눈확전두·측두극)은 fieldmap 없는 왜곡 보정 뒤에도 위치가 불확실하다 (PREPROCESSING_FINAL 2.2절).
- 입력은 469개 영역 평균이다. 영역 안 패턴, 비선형 관계에서는 결과가 다를 수 있다.

## 모델과 지표

- ridge pilot, 영역 묶음별 분석은 34개 범주도 ridge 로 예측했다 (soft BCE 기준선보다 값이 낮다). 주 결과는 soft BCE 선형 student 와 MLP student 로 보고한다.
- teacher (V-JEPA 2 + 사람 캡션) 의 평정 예측은 r 0.59 다. 내용/잔차 분해의 "잔차" 에는 teacher 가 놓친 영상 내용도 들어 있다.
- 영상 bootstrap 은 모델을 다시 학습하지 않는다 (평가 표본 변동만 반영). 피험자 5명은 같은 영상을 봤다. 일반화 범위는 같은 영상 풀의 같은 5명이다.
- MLP 는 처음에 검증 손실을 10 epoch 마다 기록해 14개 차원의 뇌 단독이 범위 끝(10)에 몰렸다. 매 epoch 기록으로 다시 돌렸고(범위 끝 비율 0), 이전 결과는 `superseded/mlp_eval_every10_20261028/` 에 있다.

## 지표에 따라 결론이 달라지는 점 (2026-10-28 추가)

- 내용 안내는 Pearson r, Spearman, 오차 제곱(R²), soft BCE, 영상별 프로필 r, top-1, 영상 짝 구별, 이진화 mAP(27개, 0.1 기준)를 모두 개선했지만, **34개 합산 MAE(GED 지표)는 나빠졌다** (soft BCE 1.947 → 1.978, MLP 1.864 → 1.911). 대부분 0 인 target 에서 MAE 는 0 에 가까운 예측(중앙값)을 선호하고, teacher 를 섞으면 0 인 영상의 예측이 올라가기 때문으로 보인다. 결과를 보고할 때 지표를 함께 밝힌다.
- 문헌 수치와의 비교: GED (TMI 2023) 34개 합산 MAE 1.64, ML-BVAE (TNNLS 2022) mAP 0.448, AESL (Brain27) mAP 0.442 는 참가자별 무작위 10겹 (같은 run·같은 내용 영상이 학습과 평가에 함께 들어갈 수 있음) 이라 우리 run 묶음 6겹보다 쉬운 조건이다. 같은 지표라도 직접 비교가 아니다.
