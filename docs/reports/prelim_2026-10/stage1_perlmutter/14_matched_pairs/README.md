# 의미를 맞춘 영상 쌍 분석 (2026-10-31, 자극 수준, 34개 감정)

질문: 시각이 정서에 작용할 때, 대상의 정체(무엇이 있나) 때문인지 생김새·움직임(어떻게 보이나) 때문인지.
코드: `perlmutter/semantic_matched_pairs.py` · `.sh`. 저수준 특징: `features/build_lowlevel_motion.py` (색 12, 밝기·선명도 6, 움직임 10) + EmoViS Sadeghi 142.

방법: 정서·평가어를 지운 캡션 임베딩에서 영상마다 가장 가까운 영상과 짝 (유사도가 가장 가까운 짝 유사도의 중앙값 이상, 748쌍).
쌍 안의 정서 차이를 특징 차이로 ridge (절편 없음, 쌍 그래프 연결 성분 6겹 교차검증) 예측한 R². 비교 기준은 같은 수의 무작위 쌍.

| 파일 | 내용 |
|---|---|
| `pairs.tsv` | 쌍 목록과 캡션 유사도 |
| `r2_by_emotion.tsv` · `r2_summary.tsv` | 감정·특징 묶음별 R² (의미가 같은 쌍, 무작위 쌍) |
| `examples.tsv` | 감정별 정서 차이가 큰 쌍과 첫 캡션 |

## 결과

- 쌍 안 정서 차이 중 평정 잡음이 아닌 부분 (라벨 신뢰도로 추정) 은 평균 36% (무작위 쌍 69%). sexual desire 78%, romance 73%, craving 72%, disgust 64%, sadness 63%.
- 의미가 같은 쌍에서 저수준 특징 (색·밝기·선명도·움직임·Gabor) 은 어떤 감정의 차이도 설명하지 못한다 (34개 평균 R² −0.006~0.001, 0.01 을 넘는 감정 0~2개). V-JEPA 2 얕은 층 (블록 8) 도 0.
- 조금이라도 설명하는 것은 남은 의미 차이 (캡션, 12개 감정에서 > 0.01; romance 0.14, empathic pain 0.08, sadness 0.07) 와 CLIP 마지막 층 (9개 감정; romance 0.15, sexual desire 0.12, nostalgia 0.10, amusement 0.08, disgust 0.06) 이다.
- 무작위 쌍에서는 CLIP 블록 24 0.32, 캡션 0.32, V-JEPA 2 블록 32 0.20, 저수준 전체 0.04.
- 해석: 이 자료에서 시각의 정서 기여는 대상·장면 수준의 의미에서 오며, 대상과 무관하게 일정한 방향으로 작용하는 저수준 효과는 보이지 않는다. 같은 색이 대상에 따라 다른 정서를 내는 경우 (갈색 초콜릿 대 토사물) 처럼 맥락에 따라 방향이 바뀌는 저수준 효과는 이 설계 (쌍 전체에 하나의 선형 규칙) 로는 검출할 수 없다.
