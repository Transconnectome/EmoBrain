# VLM 생성 캡션 점검 (2026-10-29)

대상은 EmoViS 에서 만든 `captions.json` 이다 (Qwen2.5-VL-7B-Instruct, 영상당 정지 프레임 3장 = 25·50·75% 지점, 감정어 금지 프롬프트).
사람 캡션(영상당 20개)은 오류를 표시하는 기준으로만 썼고 캡션 자체는 고치지 않았다.
코드는 `project/analysis/prelim_2026-10/features/caption_vlm_qc.py` · `.sh`.

| 파일 | 내용 |
|---|---|
| `caption_vlm_qc.tsv` | 영상 1~2185 자동 점검. 검색 순위, 사람 다수가 쓴 물체·동작 중 빠진 것, VLM 이 쓴 근거 없는 물체, 성적 내용 완화 여부, 무작위 표본 여부 |
| `summary.json` | 자동 점검 집계 |
| `review_list.json` | 눈으로 확인한 목록 (크게 어긋남 19, 바꿔 쓴 후보 상위 12, 무작위 24) |
| `visual_check.tsv` | 54개 영상 판정 (correct, minor, major, sexual_omitted) 과 원인 (프레임 밖, 보이는데 잘못 읽음, 동작, 성적 내용) |
| `sheets/` | 확인용 그림. 빨간 테두리가 VLM 이 본 3장 |

## 결과

- 자동 점검: 검색 순위 1위 48%, 500위 밖 19개. 물체를 다른 물체로 바꿔 쓴 후보 266개. 사람 과반이 노골적 성 표현을 쓴 105개 중 75개에서 VLM 은 그런 표현을 쓰지 않았다.
- 무작위 24개: 핵심 장면이 맞는 것 15개, 가벼운 오류 2개, 핵심 사건·대상 오류 5개, 성적 행위 생략 2개. 핵심 오류(성적 생략 포함) 7/24 = 29% (95% 신뢰구간 15~49%).
- 크게 어긋난 19개는 모두 실제 오류였다. 오류의 대부분은 사건이 3장 안에 보이는데 잘못 읽은 경우다. 프레임 밖이라 놓친 경우는 3개였다.
- 반복된 양상: 폭력·사고 장면을 평범한 장면으로 서술한다 (지하철 밀침, 총격, 폭행, 교통사고, 토네이도). 성적 행위를 생략하거나 돌려 말한다. 이 양상이 모델의 안전 조정 때문인지 지각 실패 때문인지는 이 자료로 가를 수 없다.

## 해석과 한계

- 검색 순위는 장면 전체가 틀린 경우만 잡는다. 핵심 사건 오류는 검색 순위 1~3위 영상에서도 흔하다 (457, 856, 1870, 2120).
- 정서 평정과 직접 관련된 사건(사고, 폭력, 성적 행위)에서 오류가 몰리므로, 이 캡션으로 "사람 해석이 빠진 내용 특징"을 재면 사람 해석 몫과 VLM 지각 실패 몫이 섞인다.
- 눈 확인은 Claude 가 영상당 프레임 5장과 사람 캡션을 보고 판정했다. 사람 검수자가 아니며, 동작 판정은 프레임 5장으로 제한된다. 무작위 표본 24개라 비율의 불확실성이 크다.
