## 1. 자료, task, 평가

- **자료.** Horikawa 2020 공개 fMRI 5명, v3_qc (QC 후 블록 반응, run 안 z; HRF 4초 지연은 전처리에서 반영). 입력은 469개 영역 평균 (Schaefer400 + TianS3 + 시상하부·BNST + 소뇌 + 뇌간).
- **target.** fMRI 참가자 본인이 아니라 Cowen & Keltner (2017) 온라인 평정자의 영상별 규범 평정. 34개 범주는 그 범주를 고른 평정자 비율(0~1, 여러 개 선택 가능), 14개 차원은 1~9점 평균.
- **task.** 차원마다 독립 회귀 (34개는 L2 선형 sigmoid + soft BCE 의 비율 회귀, 14개는 ridge). 분류가 아니다.
- **분할.** `horikawa_rungroup6_v1`: run 단위, 같은 내용 영상이 든 run 은 묶음 (61 run → 46 묶음), 6겹, 5명 공통, 안쪽 선택은 남은 5겹. fold 간 감정 분포 차이 0/34 범주.
- **평가.** 주 지표는 차원별 영상 간 Pearson r 의 평균 (Horikawa 2020 과 같음). 지표 묶음(26개)도 모두 기록 (`tables/metrics_panel_summary.tsv`).

## 2. 랩서버 재현과 검토 반영

- Perlmutter 에서 469개 영역 평균을 다시 만들어 랩서버 뇌 단독 기준선을 재현: 240개 피험자 × 차원 |Δr| 최대 0.00012.
- 랩서버 검토 4.1 (내용만과 뇌 + 내용의 영상 집합이 다름): 피험자별 같은 행·fold 에서 내용만, 뇌만, 뇌 → 내용 → 정서, 뇌 + 내용을 다시 계산 (`tables/ladder_same_rows_summary.tsv`).
- 4.4: 학습 곡선 fallback 은 업로드된 실행에서 0/1440 회 발동 (재구성). 4.5: soft BCE L-BFGS 는 모든 fit 수렴 (최대 반복 279/500). 4.2·4.3·4.6 문구 수정은 `../README.md` 에 반영.

## 3. 같은 행 비교 사다리 (5명, 34개 범주 / 14개 차원)

| 입력 | 34개 r | 14개 r |
|---|---|---|
| 뇌만 (469개 영역) | 0.329 | 0.361 |
| 내용만: 사람 캡션 (MindCaptioning 캡션 20개, all-mpnet-base-v2) | 0.629 | 0.652 |
| 내용만: 의미 annotation 73 | 0.549 | 0.596 |
| 내용만: V-JEPA 2 (ViT-g 마지막 층) | 0.477 | 0.446 |
| 뇌 → 캡션 → 정서 | 0.329 | 0.370 |
| 뇌 + V-JEPA 2 (V-JEPA 2 대비) | +0.019 (5/5) | +0.042 (5/5) |
| 뇌 + 캡션 (캡션 대비) | −0.009 (0/5) | −0.003 |

- 뇌 → 캡션 영상 짝 구별 0.90 (V-JEPA 2 0.86, 우연 0.5).
- 주의: 뇌 + 내용은 규제 강도 하나로 이어 붙인 결합이라 블록을 더하면 손해가 나는 결함이 있다 (critic 지적). 묶음별 규제로 다시 해야 결론을 낼 수 있다.

## 4. 내용 안내 teacher–student (평가 때는 뇌만)

student 학습 target = (1 − w)·실제 평정 + w·teacher 예측. teacher 는 내용 특징 → 평정 ridge 의 교차검증 밖 예측. w 와 규제 강도는 안쪽 검증으로 선택.

**결과 (5명)** — `tables/students_by_subject.tsv`

| 모델 | 34개: 뇌 단독 → 안내 | 14개: 뇌 단독 → 안내 |
|---|---|---|
| ridge pilot | 0.305 → 0.324 | 0.361 → 0.372 |
| soft BCE 선형 (34개만; w=0 은 랩서버 기준선과 같음) | 0.329 → 0.352 (5/5, 34/34 범주, 영상 bootstrap 95% CI +0.020~+0.026) | — |
| MLP (은닉 128, 매 epoch 검증) | 0.347 → 0.365 (5/5, 34/34) | 0.368 → 0.384 (5/5, 14/14) |
| 5명 통합 MLP (공통 466개 영역 + 피험자 표시) | 0.351 → 0.361 | 0.368 → 0.377 |

- 크기: soft BCE 기준 평정 분산 설명 12.8% → 14.1%, 신뢰도 상한 대비 설명 비율 16.9% → 18.9%, 뇌 단독과 캡션 사이 간격의 7.7%.
- 지표 묶음: r, Spearman, R², soft BCE, AUC, mAP27, top-1, 영상 짝 구별 모두 개선. **34개 합산 MAE (GED 지표) 는 나빠짐** (MLP 1.864 → 1.911).
- 5명 통합은 피험자별보다 낫지 않았다 (단순 결합의 한계로 보임). 통합 안에서도 안내 이득은 5/5.

**대조 (ridge pilot, `tables/teacher_variants_ridge.tsv`)**

| teacher | teacher 자체 r | student 이득 (34개) | 라벨 smoothing 대조보다 |
|---|---|---|---|
| 라벨 smoothing (내용 없음, 라벨 주성분) | — | +0.007 | — |
| 짝을 섞은 V-JEPA 2 + 캡션 | 0.591 | +0.000 | 0/5 |
| Horikawa VGG19 1000 | 0.355 | +0.005 | 0/5 |
| VideoMAE / V-JEPA 2 / DINOv2 | 0.45~0.50 | +0.008~+0.009 | 5/5 (+0.002) |
| CLIP ViT-L/14 | 0.582 | +0.015 | 5/5 (+0.008) |
| 사람 캡션 | 0.605 | +0.018 | 5/5 (+0.011) |
| 감정어 181개를 지운 사람 캡션 | 0.604 | +0.018 | 5/5 |

- MLP 에서는 라벨 smoothing 이득이 없고 (−0.007), 내용 teacher − 라벨 smoothing = +0.025 (5/5, 34/34).
- 이득은 teacher 자체 정확도에 거의 비례한다. critic 은 이를 target denoising 양상으로 본다.

## 5. 해석

- **예측 성분 분해** (`tables/networks_content_resid.tsv`, `tables/subject_softbce.tsv`): 뇌 단독 r 의 약 80% 가 내용 teacher 가 예측하는 평정 성분과 공변 (34개 85%, 14개 78%). 안내 이득 +0.023 의 89% 가 이 성분에서 나옴. 기대치 (설명 가능한 신호를 고르게 읽을 때 약 46~49%) 보다 높지만 같은 파이프라인의 null 보정은 아직이다.
- **라벨 특성** (`tables/label_characteristics.tsv`): 감정별 이득은 희소성과 강하게 관련 (0.5 이상 영상 수 순위상관 −0.72, AUC 기준으로도 −0.67). 희소하지 않은 14개 차원에서도 이득 (+0.016, 5/5, 14/14) 이 있어 이득의 존재는 희소성 효과가 아니지만, 감정별 크기 비교는 희소성을 보정해야 한다.
- **영상 특성** (`tables/video_gain_characteristics.tsv`): 길이, 머리 움직임, DVARS 와 무관. 영상별 이득의 피험자 간 상관 0.08 (개별 영상 해석 불가). 5명 모두 나빠진 영상 75개 (독립 기대 20개).
- **단어 연관 (탐색, 표 없음)**: 감정별로 다중비교 보정 후 남는 단어는 상황 단어다 (triumph: goal·victory·players·soccer 등 15개, craving: dish·chocolate·plate 등 6개, sadness: sick·injured·police, adoration: puppy·cute). 예상 가능한 연결이라 결과가 아니라 teacher 의 정상성 확인으로 본다.
- **student 가 담는 정보 (탐색)**: 정서 예측 프로필로 장면 개념 73개를 맞히는 정도가 안내 후 증가 (+0.016~+0.018, 5/5, 68~71/73 개념; 음식·스포츠·동물·군중), 라벨 smoothing 은 감소 (−0.004).
- **디코더 활성 패턴** (`tables/weights_patterns_by_emotion.tsv`): 뇌 단독과 student 패턴 상관 0.98, 감정별 이득이 클수록 패턴 변화가 큼 (+0.77), 피험자 간 패턴 일치도 증가 (0.607 → 0.617; guilt 0.42 → 0.48, pride 0.65 → 0.71). 감정 × 피질 네트워크 238칸 중 90칸이 5명 모두 같은 방향 (우연 기대 15칸). 이득이 큰 사회적 정서에서 Default 비중이 줄고 배측주의·복측주의 비중이 늘었다.
- **영역 묶음** (`tables/roi_networks_summary.tsv`, `tables/roi_networks_distill_summary.tsv`): 내용으로 설명되지 않는 몫은 시각 8.6% 에서 Default 17% 로 완만히 커지는 경사 (critic: "국소화"는 과장). 편도체·해마·시상하부 예측은 r 0.01~0.05 로 영역 평균 입력에서는 거의 측정되지 않는다.

## 6. 독립 검토와 현재 주장 문안

`critic_review_20261028.md` 참고. "정서 고유의 뇌 정보를 디코딩했다"는 주장은 하지 않는다. 현재 문안의 요지:
규범 target 은 자극의 속성이므로, 결과는 "현재 영상·캡션 모델 대비 뇌가 선형으로 접근 가능하게 하는 자극 정보의 범위"를 말한다. 내용 안내 학습의 작은 이득은 target denoising 과 같은 양상이므로 내용 접근·모델 사용 검정 전까지는 학습 전략으로 다룬다.

## 7. 진행 중 (Perlmutter)

- 공정 비교 baseline (`project/baseline/literature_comparison/`): 우리 분할과 문헌식 무작위 10겹에서 ridge, MLP, GED (공식 모델, 하위 구역 입력). GED 공개 코드는 검증 세트 없이 매 epoch 평가 성능만 출력하므로 검증 기반 선택과 평가 세트 선택을 둘 다 기록.
- 학습량: run 묶음을 유지한 10겹 (학습 90%)·46겹 (98%).
- 시각 특징 비교 사다리 (Horikawa VGG19, CLIP, DINOv2, VideoMAE).
- 캡션 단어·맥락 대조: 단어 순서 섞기, TF-IDF teacher, 범주 단어 9종 제거 (동물·음식·사람·아기와 커플·위해·성적 내용·스포츠·자연·신체 분비물), 빈도 맞춘 무작위 제거 2종.
- 희소성 통제 MLP (양성 가중치 + logit 보정).

## 8. 다음 단계와 논의하고 싶은 질문

다음 분석 후보 (우선순위 논의 필요):
1. 학습량 × 안내, 라벨 잡음 (평정자 수 축소 모의) × 안내: "이 정도 이득이면 뇌 단독으로 충분하지 않나"에 대한 답. 적은 자료·시끄러운 라벨에서 이득이 커지는지.
2. 결합 재실행 (묶음별 규제 / stacking), 분해의 null 보정, 신호대잡음 곡선 (k = 1~5명 반응 평균).
3. encoding 쪽 분산 분할 (Horikawa 2020 의 transmodal 결론과 같은 방식).
4. MindCaptioning 재현 (고정 절차, 학습 세션만, 최종 test 72개 보존), 분할 재작성 (D03).
5. 본 모델: 뇌·영상·캡션 공동 teacher, teacher loss 비교, fine-tuning 비교, 정렬을 넣은 통합 학습.
