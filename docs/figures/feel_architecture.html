FEEL: Foundation model for Emotion Embedding Learning

Track A architecture. v4 final (2026-06-02), branch v4_20260602_perlmutter.

Figure 1. Track A main architecture (Phase 3b-1.B). LoRA adaptation of a pretrained brain backbone to a frozen emotion-text embedding space.

fMRI parcel time-series는 frozen BFM backbone을 통과한 뒤 trainable LoRA adapter와 projection head를 거쳐 256-d brain emotion latent zemo로 사영된다. 동시에 emotion text (e.g. "a video that evokes admiration")는 frozen sentence-transformer를 통과해 temo가 된다. 두 representation은 InfoNCE contrastive loss로 정렬되며, V/A regression과 34-category regression head가 보조 supervision을 제공한다.

Figure 2. Phase 3b-1.A. Subject-invariant SSL pretrain (Horikawa only).

같은 video를 본 5명 subject의 brain response를 같은 latent로 정렬하는 contrastive pretraining. BFM backbone은 frozen이며 projection head만 학습된다. 학습 후 subject 간 representation의 cosine alignment를 측정하여 universal code의 subject-invariance evidence로 사용한다.

Figure 3. Phase 3b-2. Multi-source masked SSL pretrain.

4개 dataset (Horikawa, Emo-FilM, StudyForrest, Affective Videos)을 ComBat harmonization 후 같은 backbone에 통합한다. Dataset 별 learnable token이 dataset identity를 표현하고, 30% ROI를 random mask한 뒤 masked autoencoder decoder가 가린 부분을 reconstruct하도록 학습한다.
